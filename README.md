# RufMaker 原生桌面版

双击根目录的 `RufMaker.exe` 启动。界面使用 Windows Forms 原生控件和 GDI+ 绘制画布、时间轴，不使用 HTML、Edge、WebView 或本机网页服务。请保留同目录的 `studio/`、`runtime/`、`templates/`、`projects/` 和素材包。仓库包含编辑器 EXE、运行依赖、当前 GameMaker 工程及素材。GameMaker 安装目录、本地布局、游戏存档和构建缓存不纳入 Git。

## 使用

- 顶栏“新建工程 / 打开工程 / 导入歌曲”管理独立工程。新工程以“工程名/工程名.rufmaker + GameMaker.gm82/”保存；打开、切换前自动保存当前工程，重新启动恢复上次工程。旧的 `rufmaker.json` 和文本格式 `.gm82` 入口也可打开。
- 上方：保存、工程设置、检测更新、重新读取、打开 GameMaker、原生试玩、导出游戏。“工程设置”在独立窗口中修改工程名称、时间、节拍和玩家参数，应用后保存，取消不修改。工具栏随窗口宽度自动换行；侧栏只在参数区保留一层滚动。
- 左侧：对象、贴图、脚本和运动预设，可按名称筛选。双击脚本或对象进入原生 GML 编辑窗。
- 中间：房间画布。点击画布使其获得焦点后，Ctrl+滚轮以鼠标位置为中心缩放，中键拖动平移，Ctrl+0、双击中键或“适应房间”恢复取景。房间外显示暗灰透明棋盘，完整和部分位于房间外的物件、房间实例及弹幕也会正常渲染。拖动实例修改坐标，按住 Shift 可按 16 像素吸附；从资源库拖入贴图创建轨道，拖入对象创建房间实例。
- 右侧：与主时间轴共享播放头的进度条，支持按物件时段拖动、精确输入帧数/秒数、到开始/结束及逐帧移动；下方为原生参数面板。数字单击输入，按住上下拖动连续调值，Ctrl 微调、Shift 加速。滚轮不会改变下拉选择、数字或滑块的值，位于参数栏时用于滚动面板。无关键帧的属性修改全局值，已有关键帧的属性修改播放头处的值；分组标题会显示当前模式。
- 下方：音乐波形、播放头、时长和缩放控件。拖动上方刻度定位播放头。展开轨道时只显示有关键帧的属性行，主长条不再叠放关键帧；悬停长条边界会出现拉伸箭头，拖动中部平移整个物件。

更改会自动同步到当前工程的 GameMaker 文件夹（默认演示工程为 `projects/rufmaker-demo.gm82/`）。本机的原始 `engine/` 保留，不纳入 Git。GameMaker 中修改已有资源后，可点击“重新读取”更新资源库和画布。

关闭制作器时会等待当前工程保存完成，并将窗口位置、最大化状态、左右栏宽度、时间轴高度、缩放、滚动位置、展开轨道、播放头、网格选项与画布取景保存到根目录 `.rufmaker-view.json`。再次打开会恢复这些设置。

## 新工程、地形与歌曲

新建窗口可选标准底板、视频式双列错层平台、中央平台和空房间，并实时显示地形及出生点预览。双列预设默认左列 5 层、右列 4 层，可调平台宽度、列间留空、左右层数、顶部位置和纵向跨度；排列按 32 像素格生成。可附加底板、边墙、顶墙，悬空台可使用引擎原生单向平台。可自动站在最低平台，或手动输入出生坐标；还可设置房间尺寸、FPS、重力、水平速度、一段/后续跳跃速度、跳跃次数和无限跳。玩家参数可在工程设置中继续修改，地形可在 GameMaker 房间编辑器继续调整。

新工程从 `templates/avoidance.gm82/` 原始引擎模板创建，弹幕轨道和存档为空，直接进入耐久房间。分享工程时同时带上 `.rufmaker` 文件及其旁边的 `GameMaker.gm82/` 文件夹。每个工程的编译和导出文件位于该工程自己的 `build/`，默认演示工程继续使用编辑器根目录的 `build/`。

歌曲支持 OGG、MP3、WAV、FLAC。新建时可选择，也可随时从顶栏导入；音频会复制到工程 `Data/Music/`，显示原歌曲名称，重建波形，并同步到游戏和导出包。原外部歌曲文件不会被修改。导入后的时间轴匹配歌曲长度，同时保留已有末尾物件所需时长。

## BPM 与分音吸附

时间轴下方提供“按 BPM 和 x 分音吸附”、BPM、分音符和毫秒延迟。BPM 以四分音符为一拍；1/8 是半拍，1/16 是四分之一拍，也提供三连音等分法。延迟决定拍点网格相对歌曲起点的位置，可为负数。打开后拖动时间轴播放头会吸附到网格；按住 Alt 临时关闭，直接输入帧数和逐帧移动始终保留精确定位。

“自动检测 BPM / 延迟”通过原生 FMOD 无声解码及频谱起音分析估算恒定速度和拍点相位，不确定小节首拍。变速、自由节奏、复杂切分歌曲可能需要手动修正；“游标设为拍点”可快速校准。波形和检测结果缓存在工程 `cache/` 中，BPM、延迟、分音和吸附开关随工程保存。

单独选中一个物件后，可勾选“游标吸附关键帧”。拖动主时间轴或右栏播放头时，靠近该物件任一属性的关键帧会吸附；多选时暂停此功能。关键帧吸附优先于节拍，Alt 临时关闭两者，数字输入和逐帧按钮保持精确定位。开关随界面布局保存。

## 运动预设与默认房间

左栏“运动预设”提供抛物线、圆周、水平往返、垂直往返。拖到画布物件或时间轴轨道上导入，也可双击应用到单个所选物件；支持对象、弹幕发射器和整体对象。预设沿用物件起止时间，替换其位置运动关键帧，保留外观等其他属性，可撤销。转转棒导入后使用中心模式。

抛物线使用连续二次曲线，在右栏设置起点、终点和峰（曲线中点通过位置）；路径进度自带开始、中央、结束关键帧。圆周自带相角 0°、180°、360° 关键帧，X/Y 表示圆心，可独立控制公转半径、初相角和额外公转速度。往返运动自带起点、远点、返回关键帧。所有运动均同步到原生 GML，支持拖动时间轴直接求值。

RufMaker 自建工程的耐久房间首次读取时移除模板的 `objAd`、`objBackground` 及原背景设置，使用普通背景色和默认 `draw_self()` 地形；碰撞、单向平台和玩家控制保留。地形转为继承原碰撞对象的 `objRufBlock` / `objRufPlatform`，默认纯色贴图，可在 GameMaker 中继续编辑。迁移后的自定义背景和贴图不会在后续保存时重置。原始引擎模板保留；通过下面的原生导入功能创建的工程保留原绘图。

## 导入非 RufMaker 工程

1. 顶栏点击“导入非 RufMaker 工程”，选择完整的 GameMaker 8.2 文本工程文件夹。目录中有多份 `.gm82` 时可选择入口。
2. 导入窗口按控制对象名称、Step 计时、Timeline 引用及房间实例关联推荐耐久房间；可自行改选房间和控制对象，并选择供编辑器播放的歌曲。
3. 选择新工程名称和保存目录。默认保存到 `projects/imported/`，复制资源后建立 `.rufmaker` 入口，原文件夹不修改。报告保存在新工程旁的 `native-import-report.json`。旧二进制 GMK 请先通过 GM8.2 另存为文本工程。

时间轴新增独立的“GM 工程 · 原生”栏，展开后按源文件分行显示事件。支持识别递增计数的 `switch/case`、简单时间条件、固定周期，以及绑定的原生 Timeline moment；按检测到的 `timeline_speed` / BPM 换算帧数，也能解析常见 `Return_realtime` 数值表达式。点击事件定位时间，悬停显示源文件、行号和片段，双击只编辑该事件的代码块，保存时保留其他事件及嵌套的 switch；右键“编辑整个源文件”仍可打开完整 GML。原生标记不能当作普通关键帧拖动、删除或复制；修改原 GML 后重新识别。

打开导入工程后自动启用“原生游戏渲染”，首次使用会编译一个独立预览副本，将真实 GameMaker 游戏窗口嵌入编辑器，执行原有 Step、Alarm、Timeline、surface 与 3D 绘图。定位时从初始化逐帧重放到目标，保留此前生成的随机变量、实例与 Alarm；向后定位重新初始化，预览副本固定随机种子。较长的时段需要等待。暂停画面由 GameMaker 输出为图像，面板缩放不重复执行 Draw。空格播放/暂停，F5 在隐藏窗口中重放，达到目标帧并恢复 50 FPS 后才显示可操作游戏。预览期间常见 `killPlayer` 接口临时免死，F5 到达目标帧后恢复原死亡逻辑；导出保持原游戏启动流程和测试起点配置。

导入副本的全部房间统一为 50 FPS，原生轨道时长按原生事件估算；识别到最后事件切换房间或结束游戏时，以该帧作为结尾。歌曲全长不会自动拉长原生轨道。旧版导入工程再次打开时自动校正，旧设置备份至工程内 `cache/native-migration-v2/`。例如 Verse3 的结束事件为第 6700 帧，对应 134 秒。

关闭原生渲染时，静态画布只展示资源布局及 RufMaker 物件，不执行原 GML。新增 UI 弹幕会作为独立对象接入导入副本；自定义 surface/3D 管线与新增全屏特效的组合仍需要按原引擎调试。通过事件编辑器保存代码会自动重新识别并重建预览；外部修改代码后可关闭再打开“原生游戏渲染”以重新构建。玩家逻辑在原 GML 中修改。

导入窗口及完成提示会列出空 Timeline、无法换算的表达式、歌曲或初始化识别失败等情况，并给出检查建议。无法转换的代码仍由原引擎执行，不会被改写成推测的 UI 动画。随机数、外部计时/DLL、输入依赖以及在 Draw 中修改状态的代码会影响重放，需在实际工程中验收。编译失败时提示记录路径，便于在 GM8.2 修复缺失扩展、资源或代码错误。

原生预览和 F5 的运行副本位于根目录 `build/native-projects/`，以工程路径散列隔离，降低旧音频插件遇到中文工作目录的问题；导出仍在各工程自己的 `build/`。本机的 `non-ruf projects/` 输入目录、`projects/imported/` 导入副本和构建缓存不进入 Git 或程序更新包。

## 程序更新

顶栏“检测更新”读取 [GitHub 正式 Release](https://github.com/wymcaT/RufMaker/releases)，发现较新版本后自动下载 ZIP，校验整个包及逐文件 SHA256，保存当前工程和布局，关闭程序、安装并重新启动。检查与下载失败时保留当前程序。安装失败时尝试恢复覆盖前备份，更新缓存和备份位于 `build/updates/`。

更新包只包含应用、运行依赖、模板及素材库；工程、导入歌曲、存档、本地布局和 GameMaker 安装不进入包，也不被更新覆盖。Release ZIP 用于覆盖已有安装；首次使用可下载完整仓库。版本号位于 `desktop/Updater.cs`，推送对应 `v版本号` 标签后 GitHub Actions 编译并发布正式更新包。接口使用 [GitHub Releases API](https://docs.github.com/en/rest/releases/releases)。

软件图标由根目录 `icon.png` 转换为 16/24/32/48/64/128/256 像素的 `icon.ico`，嵌入 EXE 及窗口。更换原图后运行 `desktop/Convert-Icon.ps1` 并重新编译。

在展开的属性行空白处按住左键拖动，可以框选多个关键帧。Ctrl / Shift 点击可加选；拖动任意已选关键帧可整体移动，保留相对时间。复制、粘贴、删除、右键缓动和撤销均支持整组操作。新建物件默认使用全局参数，只有明确添加关键帧后才出现相应属性行。

在时间轴主行的空白处按住左键拖动，可框选多个物件；Ctrl / Shift 点击物件名称或长条可加选。拖动任意已选长条可整体平移（关键帧一同移动），拖动任意已选物件的左/右边缘可一起改变边界（关键帧不移动）。右栏可精确输入整组位置、边界和长度，并统一设置外观、拖影；Ctrl+D 复制整组，Delete 删除整组。画布空白处也能框选时间轴物件，拖动已选物件可一起移动坐标。

选中物件或物件组后，Ctrl+C / Ctrl+V 会原位复制一份完整物件，保持名称、坐标、起止时间、参数和全部关键帧，仅分配新的内部 ID。普通房间实例也支持原位复制。选中关键帧时则继续复制/粘贴关键帧到播放头。Ctrl+D 保留复制物件组到播放头的功能。

弹幕和转转棒默认保持贴图角度，不跟随发射方向或棒的角度旋转。右栏“贴图跟随发射 / 棒角度”可显式开启跟随；“贴图角度”单独控制贴图，支持关键帧。

Cherry 贴图可在右栏勾选“彩虹”，使用用户提供的 `sprrainbowcherry.gmspr` 导入的 32 帧贴图（21×24、原点 10,12）。彩虹固定白色，`image_speed=0`，通过 `image_index` 选择颜色；发射器按实际生成顺序递增，中心模式转转棒按离中心的距离对称递增，其他模式按端点顺序递增。可设置反转、动态流动、颜色密度、起始色相与流动速度；三个数值参数支持独立关键帧。密度 1 表示每个序号跨一帧，增大密度会更快跨越色谱。关闭彩虹时恢复原贴图和颜色。彩虹分帧也保留在拖影中，并同步到导出游戏。

拖影样式包括关闭、逐渐透明、逐渐缩小、缩小并变透明、透明度逐渐增大、自定义。可调生成间隔、寿命、初始不透明度、移动方向与速度，并可为每个拖影随机选择方向。自定义模式可设置每帧大小与不透明度衰减（负值表示增长）。预览中先绘制所有拖影再绘制本体；游戏中拖影使用独立对象，其深度始终大于源对象，手写 GML 修改深度时也会跟随。拖影按当前时间重建，拖动播放头后也能预览，并生成对应 GML。

右键菜单提供弹幕预设、转转棒三种端点模式、速度/加速度、圆周运动、自转、拖影和缓动。转转棒默认 5 发，可用端点关键帧改变形状，并可开启沿线段循环滚动。

## 整体对象与拉镜

点击“添加整体对象”选择转转棒、圆环或多边形；右栏“种类”也能切换，旧转转棒工程自动保留原模式。

- 转转棒：三种端点模式、棒长、循环滚动和原有关键帧功能。
- 圆环：闭合圆周等距排列，可调弹幕数量、半径、角度、自转速度、沿轮廓滚动与彩虹。
- 多边形：沿正多边形边界等距排列，可调半径、边数（3–64）、朝向与沿轮廓旋转。朝向改变外形方向，角度改变弹幕在轮廓上的相位。

半径、数量、角度、朝向、边数及滚动速度均可独立设置关键帧。闭合轮廓不会重复首尾弹幕；彩虹按沿轮廓的弹幕序号递增。整体对象在导出游戏中由真实碰撞弹幕组成。

点击“添加拉镜”创建独立轨道，X/Y 为镜头中心，“镜头缩放”大于 1 拉近、小于 1 拉远，角度用于旋转画面；这些属性支持独立关键帧和缓动。画布会显示游戏画面的虚线框，可在画布中拖动镜头中心。默认编辑器保持自由取景，勾选画布上方“渲染拉镜”才显示镜头效果；该选项不影响导出游戏执行拉镜轨道。多个拉镜重叠时，以时间轴中靠后的轨道为准，空档恢复原房间视图。预览开关随布局保存。

## 画面特效与预览

“添加特效”及右键菜单包含：闪屏、震屏、黑场/纯色遮罩、淡入、淡出、全画面 RGB 分离、动态模糊/帧混合、方向模糊、反色、暗角。可调颜色、强度、透明度、方向；动态模糊还可调采样数和帧混合比例。强度、透明度、方向、帧混合比例支持独立关键帧。淡入表示从所选颜色恢复到画面，淡出表示画面过渡到所选颜色。

特效按时间轴轨道顺序依次合成，覆盖游戏背景、玩家与弹幕；震屏和淡入淡出按当前帧计算，直接定位到特效中间也会生效。编辑器选择框和坐标手柄属于编辑界面，不参与游戏画面特效。动态模糊在连续播放时混合历史帧，大幅跳转或倒退时重置历史记录。

预览绘制保留贴图、着色参数和静态房间缓存；坐标拖动使用内存快照，并在松开后刷新完整属性面板与同步工程。新建按钮显示完整名称，空间不足时自动换行。

| 中键拖动 / Ctrl+0 | 画布平移 / 恢复适应房间 |
| Shift+滚轮 | 水平滚动时间轴 |

在文本框中输入时保留正常输入快捷键。时间轴播放包含原生音乐与声明式弹幕预览；碰撞、玩家物理和手写 GML 的实际结果以 F5 原生试玩为准。

## GameMaker 配置

编辑、时间轴预览和音乐播放可直接使用仓库中的 `RufMaker.exe`。编译/导出游戏需要安装 GameMaker 8.2 及本工程所用扩展。程序先查找根目录 `GameMaker8.2/GameMaker.exe`，再查找 `%APPDATA%/GameMaker8.2/GameMaker.exe`；其他安装位置可通过环境变量 `RUFMAKER_GAMEMAKER` 指定完整 EXE 路径。保持引擎使用的 FMOD、CleanMem 等扩展可用。

手动打开 `.gm82` 工程时，使用含 `Game Maker 8.2 Core` 和 `Game Maker 8.2 Sound` 扩展的安装。如果双击提示找不到这两个扩展，而制作器可以编译，请检查 Windows 是否关联到了另一套 GameMaker。可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File desktop/Repair-GameMakerAssociation.ps1`，将当前用户的 `.gm82` 关联修复到项目内的完整安装；其他安装位置可传入 `-GameMakerPath "完整路径\GameMaker.exe"`。脚本会先检查扩展并备份原关联到 `build/gamemaker-association-时间戳/`，不会自动打开工程。

## 原生编译和导出

点击“导出游戏”会同步工程、调用 `GameMaker8.2/GameMaker.exe` 编译并打包，然后打开 `build/release/`。分享游戏时，请同时带上 `rufmaker-game.exe` 与 `Data/` 文件夹。工程未修改时，试玩和导出会复用上次编译。

GameMaker 工程入口：`projects/rufmaker-demo.gm82/rufmaker-demo.gm82`。

构建参数顺序为 `GameMaker.exe "工程.gm82" --build "游戏.exe"`。本机 7 个旧扩展的迁移备份与 SHA256 清单位于 `build/extension-migration-20261019/`，不纳入仓库。

## GML 和原型范围

可编辑已有脚本、对象事件，或在时间轴添加按帧触发的 GML 轨道。`rf_custom_create.gml`、`rf_custom_step.gml`、`rf_custom_draw.gml`、`rf_custom_bullet.gml` 为手写代码钩子，同步时保留。

拖动播放头会重建声明式弹幕和关键帧轨道。任意手写 GML 在过去帧产生的副作用尚未自动回放；可在初始化钩子中重建必要状态，再用原生试玩调试。
