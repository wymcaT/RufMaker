# 自己排列右栏页面

2.4.0把右栏拆成 **常规设置** 和 **关键帧** 两个可停靠页面。常规设置保留属性、行为、统计三个页签；选中关键帧后的帧数、数值、表达式和缓动放在关键帧页。

物件的小时间条也位于关键帧页顶部，包括物件时段开关、起点/终点按钮、开始帧和结束帧输入。它与下栏共用播放头，随关键帧页一起停靠或合并为页签。

时间轴、属性区、资源列表和代码编辑器的原生滚动条统一使用暗色样式；滚轮、拖动和键盘操作保持原有方式。

## 用鼠标改变布局

1. 按住页面上方带 **⠿** 的标题栏拖动。
2. 拖到另一页面的左、右、上、下边缘，出现停靠预览后松开，即可分成对应布局。两页的顺序也能互换。
3. 拖到中间并松开，会合并为两个页签。按住页签标题再拖到边缘，可以重新分栏。
4. 拖动两页之间的粗分隔条，调整宽度或高度。右栏外侧的分隔条仍可以扩大整个右栏；关键帧页内的分隔条单独调整列表与详情的高度。

标题上的 **⋮** 或标题右键也可直接选择停靠方向、合并页签或恢复右栏默认布局。拖出右栏后松开，或在拖动中按 Esc，会取消这次布局调整。

## 编辑与保存

在关键帧列表选中一帧，其详情会显示在同一页内。常规属性保持自己的行与滚动位置；切换物件、增删关键帧或撤销不会还原停靠布局。

布局、顺序、当前页签、左右宽度比例、上下高度比例和关键帧详情区大小都随工作区保存，下次启动恢复。这些是界面偏好，不写入弹幕工程，也不占用工程撤销记录。旧版的关键帧区高度会迁移到新的上下布局；旧版已收起的关键帧区会改为页签布局。

布局作用范围为右栏内。横向分栏时可以先拉宽右栏，让两个页面都有足够空间。
