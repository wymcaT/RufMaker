# UI 操作安全改进

基线：GitHub main `e8a89c338f41f9d33428c0315701ac628cce8764`。本轮在隔离源码工作区实现，用户已授权修复后推送 main；不发布、不修改用户工程、不重建 EXE。

## 操作变化

- 素材列表单击贴图只浏览，不更换所选物件。双击或下方“应用贴图到所选（数量）”才应用；仅处理所选可视物件，混选的拉镜等轨道不变；重复应用同一贴图不新增撤销。
- 工程状态区分“修改待保存”“正在保存”“已保存”“保存失败 · 修改未保存”。失败不会每 400 毫秒弹窗；保留修改，并提供“重试保存”和 Ctrl+S。其他状态提示不会清除失败标识；加载/忙碌状态结束后统一刷新按钮，保存失败可以立即重试。
- GML 的保存按钮和 Ctrl+S 保存后保持窗口；关闭有未保存文本时提供保存、放弃或取消。保存期间禁止关闭和重复提交；保存过程中继续输入的文本不会误记为已保存。保存失败后关闭会明确提示：已提交修改可能仍留在主工程，并非事务性回滚。
- 原生对象动作、路径/时间线资源、实例创建代码和原生事件连续保存时更新版本校验值；新增代码动作只新增一次，后续保存编辑同一动作。外部修改仍触发冲突保护。
- 导出先确认工程保存成功，再提示后台正在同步、编译和打包；不展示未经后台支持的百分比。成功后若有 previousDir，状态栏提供“打开旧导出备份”。备份可能只有差异文件，不能当作完整游戏运行；目录打开失败不再误报导出失败。
- 属性文字、下拉与数值可用 Tab 导航；数值有焦点框，Enter/F2 编辑。按钮增加属性名、提示与可访问说明。◆/◇ 仍表示是否启用关键帧，不声称该时刻一定存在关键帧；未改变 Motion 编辑规则。聚焦原生按钮/复选框时空格保留标准操作，画布空格仍走预览。
- 本地教程支持搜索、Enter/F3 下一处、Ctrl+F 定位搜索和循环查找。
