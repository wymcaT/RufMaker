# 轨道共享组与组事件

组用来把同一段弹幕、控制事件放在一起管理。一个组可以包含多条轨道；同一轨道上的全部物件共享所属组。时间轴的轨道底色与名称旁的组名表示归属，物件自身的颜色仍然表示种类。

## 建组与调整

选中物件或轨道，右键选择 **轨道归属组 → 新建组并加入**。多选分布在几条轨道上的物件，可以一次把这些轨道并入同一组，轨道上的其他物件也一起归组。

同一菜单里可以加入已有组、不分组、重命名、改底色、选中组内全部物件或解散组。解散只移除分组，不删除物件。移动物件到其他轨道时，它采用目标轨道的组；自动分离重叠物件与“整理时间轴”会保留原有的归组关系。操作可以撤销，归属、名称和底色随工程保存。

右键主菜单保留常用的复制、粘贴、删除和关键帧入口。生成行为、保存预设、移动轨道等操作放入“更多物件操作”；新建内容集中在“添加物件或事件”。

旧工程中的父子坐标变换继续保留，参数页称为“变换父级（旧工程）”。新的轨道共享组不会改变坐标、缩放或动画。

## 三种组事件

左栏 **预设 → 事件**，或右键 **添加物件或事件 → 添加事件**：

| 事件 | 效果 |
| --- | --- |
| 复制组内所有弹幕一遍 | 在事件开始帧复制一次。包括飞行子弹、未释放的整体成员、生成模板和联动副本的成员；整体对象只复制可见成员，不复制生成器。 |
| 清除组内所有弹幕 | 移除组内当前弹幕和当前整体成员；发射器继续工作，未来物件仍可出场。拉长事件可持续清除。 |
| 设置组内所有弹幕属性 | 设置速度、方向、加速度、每帧转向、大小、不透明度或颜色。拉长事件可在时段内每帧执行，接收新生子弹。 |

目标默认是事件所在轨道的组，也可在右栏“目标组”明确选择另一个组。事件没有所属组或目标组被删除时，不会作用到其他组，右栏会显示提示。

复制事件保留触发瞬间的位置、贴图帧、颜色、大小与不透明度。副本具有独立寿命，不继承原弹幕的追踪、加速或生成行为；默认速度为0。右栏可以另设速度、方向、加速度、转向、寿命模式，以及是否使用来源拖影。之后的时间轴事件仍可控制副本。副本继续属于来源组。

**是否销毁原弹幕**默认关闭。开启后先复制当前弹幕，再立即移除参与复制的原弹幕；整体成员不会在下一帧重新长回来。发射器、未来子弹、其他组与新副本会保留。

**副本寿命模式**与普通弹幕、释放后的整体成员、生成模板统一为三种：固定寿命（按帧计时）、出屏幕销毁（按房间边界）、出视野销毁（按当前游戏镜头，可旋转/缩放）。选择出界模式时显示“出界余量”，固定帧数不再限制寿命；出生即在对应范围外也会销毁。边界按弹幕中心判断。普通弹幕的寿命数值与模式都放在“弹幕寿命”分类中。

未释放的整体成员位置由整体对象的关键帧控制。组事件可调整其大小、不透明度和颜色；独立速度、方向等运动设置作用于飞行子弹。普通贴图装饰、玩家、地形、镜头和画面特效不属于这里的弹幕。

## 在运动框里输入公式

运动重设、弹幕年龄行为的起止值、生成模板的速度与方向、副本朝向等数值框支持直接填写公式，也可点击左边的随机/公式按钮：

```text
random_range(2,5)
random(360)
choose(0,90,180,270)
point_direction(x,y,player.x,player.y)
point_direction(source.x,source.y,x,y)
```

例如，把同一组弹幕暂停后，在某个节拍复制一份：复制事件的速度填 `random_range(2,5)`，方向填 `random(360)`。想按各颗弹幕相对来源中心的位置向外散开，方向填 `point_direction(source.x,source.y,x,y)`。

组事件按每颗目标弹幕取样。相同工程、种子与历史会重建相同结果；“重新随机”会换一组结果，游玩时沿用工程的固定/随机种子设置。`player.x/y`、坐标和时间变量沿用参数表达式语法。

组设置事件的一帧操作完成后，弹幕自身后续的运动行为仍可能继续改变属性。如果要取消后续追踪或运动，使用“重设所有子弹运动属性”中的“停止后续运动行为”，或调整来源的年龄行为。

组事件作用于 RufMaker 管理的弹幕与其后代。导入工程的原生底片是一段已录制画面，不能通过组事件修改；原生对象可用现有全局事件的“额外原生弹幕对象”在 F5/导出中控制。自定义预设保存事件参数与表达式；跨工程导入时，需要重新选择仅存在于原工程的显式目标组，或选择跟随事件轨道。
