# 弹幕行为、整体对象与生成模板

这些功能已并入 `1.12.0` 正式版，程序为根目录 `RufMaker.exe`。本文件保留原路径，方便此前测试版链接继续访问。

旧版编辑器不认识新增行为字段，用旧版保存包含这些功能的工程可能丢失设置。

## 从哪里开始

1. 添加一个弹幕发射器，选中后点击下栏 **弹幕行为…**，或右键选择 **编辑弹幕年龄行为…**。
2. 先试行为预设 **减速 → 瞄准 → 冲刺**。每颗弹幕都会从自己的出生第 0 帧执行这套动作。
3. 行为窗口中可添加、复制、删除和排序动作。拖动上方条块改开始年龄，拖右边界改持续帧数。列表靠后的同属性动作优先。
4. 返回主时间轴拖动查看，按 F5 从播放头试玩。年龄行为、控制事件和阵列都会同步到 GameMaker 工程。

## 两套时间怎么区分

- **歌曲时间轴**控制发射器何时工作，以及何时给已经生成的弹幕下指令。
- **弹幕年龄**从每颗弹幕出生开始计数。第 20 帧出生和第 120 帧出生的弹幕，都会分别在出生后第 30 帧执行年龄 30 的动作。
- **每颗延迟**按编号 `i` 错开：实际开始年龄为 `开始年龄 + i × 每颗延迟`。

支持的年龄动作：弹速、方向、大小、不透明度、每帧转向、每帧加速、瞄准一次、限制转速追踪、碰撞开关、销毁、分裂/子发射器。数值变化可选择缓动；公式留空时使用起始值、结束值。

“相对出生值”对方向与弹速表示相加，对大小与不透明度表示相乘。碰撞值 0 关闭、1 开启，外观继续显示。瞄准一次默认使用零时长；需要持续跟踪时使用追踪动作。

## 控制已经生成的弹幕

点击 **添加弹幕控制**。选中单个发射器时，默认以它为来源；也可在右栏改为全部来源或其他发射器。

可筛选来源、标签、齐射编号、奇偶编号和年龄范围。可改变速度、方向、大小、不透明度、每帧转向、加速、瞄准、追踪、碰撞、颜色或销毁。

- 零长度事件：在指定歌曲帧瞬间改变。
- 有长度事件：按起始值到结束值进行变化，可设置缓动或逐帧公式。
- 关闭“包含期间新生弹幕”：只选中事件开始时已经存在且符合条件的弹幕。
- 开启该选项：事件期间也接收后来符合条件的弹幕。

年龄行为先执行，全局控制事件随后执行，因此同一帧的控制事件可以覆盖年龄行为。

## 阵列、曲线与编号

右栏“发射阵列”中可选择点、直线、圆环、圆弧、椭圆、正弦曲线或贝塞尔曲线。宽度、高度、圆弧角度、相位、旋转与波形周期数可以分别设置关键帧。

贝塞尔阵列选中后，画布显示 P0–P3 四个控制点。拖动修改，Shift 按 16 像素吸附。

可选择扇形、固定、径向、沿切线或出生时瞄准玩家的方向，并设置逐颗延迟、速度递增、方向递增和大小比例递增。

表达式新增：

| 变量 | 含义 | 示例 |
| --- | --- | --- |
| `i` | 本轮编号，从 0 开始 | `3+i*0.2` |
| `n` | 本轮弹幕总数 | `360/n` |
| `u` | 编号映射到 0–1，单颗时为 0 | `sin(u*2*pi)*30` |
| `volley` | 齐射编号，从 0 开始 | `volley*15` |
| `age` | 行为公式中为弹幕年龄 | `turn_towards(direction,point_direction(x,y,player.x,player.y),3)` |

出生参数中的随机数可以按每颗、每轮齐射或整个发射器共用一次取样。已有“重新随机”和固定/随机游玩种子继续使用。行为逐帧公式中的随机按执行帧确定，拖动时间轴不会自行换一组。

## 整体形状

点击 **添加整体对象**，可选择转转棒、圆环、多边形、心形（heart）、星星（star2）、星形轮廓、椭圆、花朵、∞ 形。选中后也能在右栏“种类”中切换。

心形和星星使用用户提供的 `Verse3/scripts/heart.gml`、`star2.gml` 的公式。星星保留原脚本 k→k+2 的交叉连线；星形轮廓是另一个可调内凹比例的种类。原脚本原样保存在 `assets/gml/formations/`，工程缺少同名脚本时自动补入，已有版本保留，可继续直接写 GML 调用。

- 半径控制轮廓尺寸；轮廓朝向旋转整个形状，角度控制弹幕沿线的相位。
- 边数 / 尖角数用于多边形、星星、星形轮廓，花朵中表示花瓣数。
- 轮廓高度比例用于拉伸，星形轮廓和花朵还能调内凹比例。
- 这些参数支持独立关键帧、表达式、复制和预设；已有彩虹与拖影继续适用。
- 非圆曲线按参数排列，滚动速度通过轮廓长度换算；`star2` 按原脚本逐段排序。控制整形旋转请使用轮廓朝向。

修改单项属性后的 Ctrl+Z / Ctrl+Y 保留物件、属性关键帧、多选和右栏上下文；撤销删除时也会选中恢复的物件。

## 生成一个按固定模式行动的物件

1. 在时间轴做好模板：可用普通物件、整体对象、发射器或分组，保留其运动、关键帧、彩虹、拖影及弹幕行为。
2. 勾选模板右栏的 **仅用作生成模板**。它不自行参与歌曲播放，仍可在时间轴选中和编辑。
3. 选中来源，右键 **物件生成行为…**，添加 **生成模板**；也可在飞行弹幕的 **弹幕行为…** 中添加同名动作。
4. 选择模板，设置开始年龄、偏移、是否继承方向，以及是否 **生成后销毁母体**。

物件生成行为的年龄从来源物件的开始帧计算；弹幕行为从每颗弹幕出生计算。每个模板实例独立从模板自己的开始帧运行：以原始起点为锚，平移到触发位置，再应用可选的母体方向旋转。生成的发射器发出的弹幕会独立飞行，整体对象则持续执行自身关键帧，直到结束或释放队形。

- **生成位置**：整体中心，或各颗弹幕。中心模式销毁整件；成员模式可按奇偶与编号区间只选择和销毁部分成员。
- **重复间隔**：0 只触发一次；大于 0 时按间隔触发。重复时持续帧数 0 表示直到母体结束，正数表示触发窗口（包含边界）。每颗延迟仍生效。
- **最大生成代数**：原来源为 0 代。要让第一代继续生成第二代，将相应动作上限设为至少 2；最高 4。
- 生成物不跟随母体后续移动，也不因母体销毁而消失。倒拖、F5 起点重建和随机种子保持可重建。
- 保存来源为自定义预设时，会带上引用模板及其分组成员、贴图；导入、复制和 FPS 换算会保留并调整模板引用及重复间隔。

例如：樱桃在年龄 50 生成一个心形后销毁；心形以当前位置为中心，按自己的关键帧放大、旋转和上移。

## 分组、释放和分裂

- 多选发射器、整体对象或贴图对象，右键 **将所选物件创建为分组**。父级的移动、旋转、大小和透明度作用于子物件；子物件使用组内坐标。
- 发射器发出的普通弹幕随后独立飞行。整体对象则维持队形，直到设置的 **释放队形的歌曲帧**，随后沿径向、切线、指定角度或玩家方向飞出。
- 在年龄行为里添加分裂。母弹保留，子弹从母弹当时的位置生成，以母弹方向为中心展开。默认继承外观且不继续执行母弹行为；也可选择另一个发射器作为子弹模板。模板可禁用以避免自行发射。代数可设置为 1–4。
- 复制分组或保存为自定义预设时，会保留子物件与内部关联。

## 循环片段

选中一段物件，右键 **组合为可循环弹幕片段**。片段可设置循环次数、循环间隔和播放倍率，可以再与其他物件组合为更大的片段。片段也能保存到已有的公共自定义预设库。

需要编辑内部物件时，右键 **拆开片段以编辑内部物件**，会展开全部循环；修改后可以重新组合。片段里的数值关键帧与行为时长随倍率调整；手写表达式的 `frame/time` 仍表示歌曲绝对时间。

## 试玩轨迹与定位

F5 试玩会记录玩家位置。游戏退出后，编辑器自动载入最后一次重试的轨迹并勾选 **使用试玩轨迹**。也可以点 **载入玩家轨迹…**，选择试玩目录 `Data/rufmaker_player_trace.csv`。

有记录的时间段按真实走位预览追踪和瞄准，记录之外使用右栏设置的参考玩家位置。取消勾选可恢复固定参考位置。轨迹随 RufMaker 工程保存；导出游戏仍读取实际玩家位置。

新增弹幕模拟从历史逻辑重建，并缓存检查点以加快倒拖。外部 GM 原生工程的底片工作流保持原样，新控制用于 RufMaker 新增的弹幕。

## 构建

运行 `desktop/Build-Native.ps1 -Output D:\rufmaker\RufMaker.exe`，生成正式入口 EXE。

激光、区域力场和局部合成等后续候选功能还未加入这一版。
