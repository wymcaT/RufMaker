# RufMaker 2.6.0

首次下载请选择 **RufMaker-2.6.0-Windows-Portable.zip**，完整解压后打开 `RufMaker.exe`。已有版本可使用“检测更新”；`RufMaker-2.6.0.zip` 是供软件更新器使用的兼容更新包。两种包都附有 SHA256 校验文件。

## 区域内随机生成

- 左栏新增“区域内随机生成”弹幕生成模板，拖到来源物件后即可循环执行。在右栏“行为”页设置间隔、每次数量和矩形中心、宽度、高度。
- 每颗弹幕独立在矩形内取样，速度与方向支持 `random_range(...)`、`choose(...)` 等公式。默认使用房间坐标，也可开启“区域跟随来源”；选中来源时显示青色区域框。
- 新生弹幕可设置出生淡入和淡入帧数，独立使用固定寿命、出屏幕销毁或出视野销毁；保留拖影、销毁过渡和后续年龄行为。
- 发射器来源默认按整件生命周期触发，避免因每颗已发弹幕重复执行而意外倍增；需要时仍可切换为逐颗弹幕触发。

## 颜色与彩虹

- 新建弹幕和生成模板默认混色为白色，已有工程的颜色保持不变；需要来源外观时可主动开启继承选项。
- 彩虹增加“随机彩虹颜色”：每颗选择一个随机初始颜色，出生后保持；开启动态色彩时从该颜色继续流动。
- 随机结果沿用工程种子，倒拖不改变结果，“重新随机”可重新取样；整体对象释放时保留对应成员的随机配色。

## F5、R 与复制性能

- 减少复制对象的重复几何计算、无用轨迹保存和成员初始化开销，保持副本与来源参数的联动。
- 普通 F5 增加准备进度与取消，跳过不影响后续结果的已结束弹幕历史。首次启动仍需要运行器加载和必要的历史计算。
- 第一次到达测试位置时保存完整状态；R 在同一游戏进程内直接恢复，不再重跑创建事件或整段历史。测试点之前的弹幕和随机结果保留，之后按工程的固定/随机种子设置继续。
- 修复快速连续按 R 后 `bloodEmitter` 的粒子资源残留。恢复期间也会阻止重复死亡特效，不清空场景里的装饰粒子。

区域、随机颜色及寿命通过18个时刻、2,532条完整状态的真实GM/预览对照；R快照、快速重试与复制性能另有定向验证。本版没有重新录制整段外部原生工程底片。
