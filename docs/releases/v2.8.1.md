# RufMaker 2.8.1

首次安装请下载 **RufMaker-2.8.1-Windows-Portable.zip**，完整解压后运行 RufMaker.exe。已安装的用户可以在编辑器点 **检测更新**，更新器会使用 RufMaker-2.8.1.zip。

## 密集弹幕预览

- 预览默认启用 Direct3D 11。弹幕本体和拖影按原深度顺序绘制。RGB 分离和方向模糊可以和场景一起在显卡中完成，整帧只需读回一次。缺少可用图形设备时会自动使用 CPU。
- 相邻帧复用拖影的历史位置和贴图帧。暂停、缩放或倒拖后，预览仍按对应的时间和视口生成。
- 打开 **预览 → 显示 → 预览分项耗时** 可以查看耗时、GPU 合成和回读次数。同一菜单可以切换 GPU 加速。

在 RTX 4060 Laptop GPU 上测试每帧绘制 2,185 次贴图的场景，同时开启 RGB 分离和九采样方向模糊。800×608、预热后的连续 60 帧平均用时约 4.7 ms。另用 720×550 的 WinForms 预览控件按 50 Hz 绘制到内存画布，发行构建的 300 帧全部在 20 ms 内完成。实际速度取决于工程、画布尺寸和显卡。以上数据衡量编辑器预览，F5 运行的游戏由 GameMaker 执行。

## English

Download **RufMaker-2.8.1-Windows-Portable.zip** for a first installation, extract it and run RufMaker.exe. Existing users can select **Check for updates**.

Dense bullet and trail previews now use Direct3D 11 by default on supported hardware. The editor can composite sprites, RGB separation and directional blur with one GPU readback per frame. The preview’s **Display** menu includes GPU acceleration and per-frame timings. CPU rendering remains available.
