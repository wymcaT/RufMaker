# RufMaker 2.7.0

首次下载请选择 **RufMaker-2.7.0-Windows-Portable.zip**，完整解压后打开 `RufMaker.exe`。已有版本可使用“检测更新”；`RufMaker-2.7.0.zip` 是供软件更新器使用的兼容更新包。两种包都附有 SHA256 校验文件。

## 重设弹幕属性

- “重设所有弹幕属性”和“重设组内所有弹幕属性”现在能正确控制整体对象，以及圆周、网格、分组和嵌套复制出来的成员。
- 触发重设时，成员保留当时的位置、大小、颜色和贴图朝向，脱离原容器后按新参数独立运动。原整体结束不会再把它们一起带走；未来物件和发射器仍按原计划工作。
- 速度、方向始终可见，支持数值、`random_range(...)`、`choose(...)` 等公式。新事件默认使用自定义参数；修改旧事件的数值或公式会自动关闭“恢复出生速度与方向”，撤销会一起恢复。
- 两类事件都可重设寿命、加速度和转向，并选择是否停止后续运动行为。
- 修正网格循环后错误的径向方向，以及 F5 跳到重设之后时漏掉寿命被延长的弹幕。

## 试玩和玩家预览

- **F5** 保持普通试玩，**F6** 进入无敌调试，便于检查弹幕和记录走位；正式导出保留原游戏的正常受伤规则。
- 试玩记录玩家的位置、实际贴图和动画子图、镜像、大小与角度。启用“使用试玩轨迹”后，预览中的玩家与场景在同一帧渲染，不再铺满整段轨迹线。
- 自机狙预览参考对应帧的玩家位置；编辑器引导线跟随已显示的预览帧。

## 音乐同步

- 游戏按逻辑时间检查音乐进度，卡顿造成小幅偏差时轻微调整播放速率，偏差超过 8 帧时定位校正，并设置冷却避免连续跳动。
- 暂停、停止或曲终时不会强制继续播放。按 R 恢复测试点时也会恢复校时状态。
- 外部原生工程已有的音乐校时继续保留；仅在能识别 FMOD 与逻辑时钟、且缺少原生校时时添加观察对象。

重设修复通过真实 GM 的 25 个时间点、3,986 条状态对照与 F5 重建验证；音乐校时已用真实 FMOD 和模拟卡顿验证。原生底片仍是缓存录像，重设事件不能修改已录制的画面。
