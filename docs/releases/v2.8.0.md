# RufMaker 2.8.0

首次下载请选择 **RufMaker-2.8.0-Windows-Portable.zip**，完整解压后运行 `RufMaker.exe`。已安装 RufMaker 的用户可以在编辑器里点 **检测更新**，由更新器下载 `RufMaker-2.8.0.zip`。

## GM 对象和弹幕编辑

- 双击原生 GM 对象，可以按事件查看和编辑动作。资源库也支持新建和删除对象。
- 在“资源 → 对象”里右键选择“转换为可编辑物件”，可以把简单对象的初始化转换为时间轴上的独立弹幕来源。遇到需要 GM 执行的 Step、Draw、碰撞或继承逻辑时，编辑器会列出原因，并提供保留原生片段的选项。
- 从左栏“物件属性”拖入“弹幕物理”或“贴图动画”，即可设置加速度、阻力、重力、动画起始帧和播放速度。对象和整体对象可以调整绘制深度。

## 界面、保存和预览

- 更新了时间轴与属性栏的布局和配色，可选属性集中在可折叠栏目。按 F1 或 Ctrl+Shift+K 可打开命令面板。
- 工程打开或保存失败时可以保留编辑现场并重试。重复导出会处理已经删除的资源，并保留存档和手工添加的文件。
- 暂停重绘同一帧时，动态模糊会保留前帧的混合。离开动态模糊或故障转场片段后会释放对应的画面缓存。这个修复同时应用于编辑器预览和生成的游戏。

First installation: download **RufMaker-2.8.0-Windows-Portable.zip**, extract all files and run `RufMaker.exe`. Existing users can select **Check for updates**. This version adds native GM object editing and conversion, optional bullet physics and sprite animation, a searchable command palette, and fixes for paused motion blur and effect memory use.
