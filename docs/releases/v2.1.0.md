# 2.1.0（本地构建）

- 左栏新增“弹幕生成模板”：保持形状扩散、统一速度扩散、360°随机弹、对玩家自机狙、溅射弹幕。拖放或双击自动创建循环生成规则与绑定模板。
- 右侧行为页直接调整间隔、首次延迟、弹速、数量、寿命；溅射支持每轮随机初相位和固定角度递增。
- 新弹幕可独立选择寿命/越界销毁模式、销毁过渡和完整拖影样式，并通过“新弹幕行为…”编辑年龄动作。移动母弹可在自身寿命内循环发射，来源方式可切换。
- 新增时间轴全局变量，支持一次/重复赋值、默认值、变量间引用以及 `global.name` 参数表达式；随机历史可复现，支持倒拖和F5中途恢复。
- 复制和自定义预设携带生成模板及变量依赖；变量名称冲突会自动改名并更新参数引用。
- 本次未推送或发布 GitHub Release。

使用方法见 [弹幕生成模板与全局变量](../generation-presets.md)。
