# RufMaker 2.0.0

这次重整了原生 Windows 界面，把空间还给预览、轨道和参数编辑。

**首次下载：选择 `RufMaker-2.0.0-Windows-Portable.zip`，完整解压后运行 `RufMaker.exe`。**

`RufMaker-2.0.0.zip` 是“帮助 → 检测更新”使用的兼容更新包。两个 ZIP 都附有 SHA256 文件。更新保留个人工程、歌曲、底片、自定义预设与设置；GM8.2 仍通过“工具 → 引擎设置”按需配置。

## 界面入口

- 顶栏改为文件、编辑、视图、工程、工具、帮助六个菜单；主工具行集中添加、撤销/重做、保存状态、F5 试玩和导出。
- 左栏分为素材/预设两页，分类、搜索和拖放保留；自定义预设的导入导出、重命名与分类集中在“管理”。
- 右栏分为属性/行为/统计。属性按分组折叠，关键帧状态保留在原参数行。行为页可直接编辑常用生成/年龄参数，“展开编辑”打开完整规则编辑器。
- 右栏保留共享进度条与物件起止帧；移除重复的大面积帧/秒定位框和底部操作按钮。
- 时间轴只保留一行播放、逐帧、时间、倍速、音量、吸附和缩放工具。BPM、分音、延迟与自动检测在“吸附”面板中设置；波形/频谱仍在音频轨右键切换。
- 工程设置、底片管理、语言、引擎、教程和检测更新各自归入对应菜单。工具栏使用原生溢出菜单，窗口变窄时不再不断换行。

## 生成组与模板编辑

- 来源物件、生成规则、模板引用同轨显示。模板卡片即使只发射一次也保持可读宽度，注明局部时间与共用关系。
- “视图 → 只展开当前生成组”减少无关行；仍可手动展开多个组并保存布局。
- 双击模板引用进入局部预览，点击“返回来源”恢复原歌曲时间与选择。局部预览不播放歌曲；F5 返回来源位置进行真实试玩。
- 属性切页、折叠和数值/关键帧撤销继续复用控件；保留原有快捷键、复制粘贴、多选与关键帧边界限制。

本版也包含上次正式版之后的弹幕寿命/越界销毁、缩小/透明销毁过渡、周期与逐成员生成、继承出生外观和大小、波次随机颜色等本地改进，详见 README 和示例教程。

## English

For a first installation, download **`RufMaker-2.0.0-Windows-Portable.zip`**, extract everything and run `RufMaker.exe`. `RufMaker-2.0.0.zip` is the compatible in-app update package. Both have SHA256 checksums.

2.0 reorganizes the native Windows UI with six menus, fixed command and playback bars, Assets/Presets browsing, collapsible properties and Property/Behaviors/Statistics pages. Common behavior parameters can be edited inline; the full editor remains available. BPM controls are under Snap, native recordings under Project, language and engine setup under Tools, and updates under Help.

Generation rules and template references share the source track. Double-click a template for local preview, then Return to source to restore the original song position and selection. Local preview is silent; F5 returns to the source before playtesting. Existing shortcuts, GML editing, game export and user data are preserved.
