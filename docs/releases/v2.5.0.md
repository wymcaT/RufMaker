# RufMaker 2.5.0

首次下载请选择 **RufMaker-2.5.0-Windows-Portable.zip**，完整解压后打开 `RufMaker.exe`。已有版本可使用“检测更新”；`RufMaker-2.5.0.zip` 是兼容旧版本更新器的更新包，继续使用原 SHA256 校验。

## 轨道共享组与组事件

- 右键轨道可设置所属组，多条轨道可以共享一组；用不同底色区分，改名、改色和归组均可撤销并随工程保存。右键菜单收纳为常用操作与子菜单。
- 新增复制、清除和设置组内弹幕属性的事件。复制只复制当前弹幕和整体对象成员，不复制生成器；可选择立即销毁原弹幕。
- 副本及其他弹幕寿命统一支持固定帧数、出屏幕销毁、出视野销毁，可设置出界余量。速度、方向等运动参数支持 `random`、`choose` 等公式。
- 时间轴事件改用圆点标记准确触发时间，名字写在右侧；长物件滚出左侧后，名称仍留在可见范围内。

## 预设更容易编辑

- 动作与拉镜预设直接按参数计算，不再铺满属性关键帧。受控属性显示“由预设控制”，右栏可调整中心、幅度、速度、时长等参数，其他属性仍可单独加键。
- 未手动改动的旧预设会转换为参数驱动；修改过或不能可靠识别的旧曲线继续保留。
- 拖动、裁剪、变速和跨 FPS 复制保持预设时间；预设内部采样不再干扰游标吸附。

## 自机狙读取实时玩家位置

- 出生、整体释放、逐颗延迟和模板生成在真正触发的帧读取玩家坐标，持续追踪每帧读取；单次瞄准仍只瞄准一次。
- 预览使用启用的玩家轨迹或编辑位置，F5/导出使用游戏里的实时玩家。原生底片录制参考位置仍为 `(400,304)`。

## 保存、预览和撤销

- 保存先准备全部生成内容，再提交工程数据和 GM 资源；失败回滚，进程中断后可通过工程内 `.rufmaker-sync` 恢复。若提示回滚尚未完成，请保留该目录并重新打开工程。
- 取消过时预览请求，只显示与当前场景/时间一致的画面和统计。重用未受影响的模拟历史，后段改键从受影响区段重算，倒拖保留分层检查点。
- 移除原先 200 个物件/轨道的限制及简化预览 20000 颗弹幕的静默绘制截断。
- 撤销和重做共用估算内存预算，默认128 MiB，可在“工具 → 撤销内存预算”选32/64/128/256 MiB。超额淘汰最早记录，保留最近一步。
- 预览错误写入状态栏和 `user-data/logs/preview.log`，连续相同错误去重。

已完成定向自动测试与真实 GameMaker 数值对照：实时玩家1502条状态、动作/拉镜768个姿态、组事件及寿命测试，以及1000物件启动/绘图。Verse3隔离导入叠加后保存、代码保留和编译通过，本轮没有重录整段底片。复杂场景首次跳到后段仍需要计算历史，预算按估算管理，不代表整个程序内存上限。

升级前建议保存工程副本；新字段与参数预设不适合交回旧版本保存。用法：[轨道组](https://github.com/wymcaT/RufMaker/blob/main/docs/timeline-groups.md) · [动作与时间轴](https://github.com/wymcaT/RufMaker/blob/main/docs/motion-timeline-editing.md) · [性能与保存](https://github.com/wymcaT/RufMaker/blob/main/docs/performance-and-saving.md)。
