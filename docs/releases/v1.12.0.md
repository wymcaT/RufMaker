# RufMaker 1.12.0

弹幕控制测试版功能正式并入主版本。

- **生成模板**：物件或飞行弹幕可以生成带独立运动与关键帧的物件、整体对象、发射器或分组。支持循环触发、成员/奇偶/编号筛选、偏移、继承方向，以及生成后销毁母体。
- **弹幕行为**：按出生年龄设置减速、转向、瞄准、追踪、碰撞、销毁和分裂；歌曲时间轴可以控制已经生成的弹幕。
- **分组与片段**：父子变换、整体队形释放、可循环片段、玩家试玩轨迹和可重建的倒拖预览。
- **更多整体形状**：来自原 GM82 工程 `heart` / `star2` 脚本的心形、星星，以及星形轮廓、椭圆、花朵和 ∞ 形。支持独立属性关键帧、彩虹和拖影。
- 修复修改单项属性后撤销丢失物件选中的问题，保留关键帧、多选和右栏上下文。
- 自定义预设携带引用的生成模板与资源，跨工程导入后继续工作。

首次下载请选择 **RufMaker-1.12.0-Windows-Portable.zip**，完整解压后运行 **RufMaker.exe**。

**RufMaker-1.12.0.zip** 是供“检测更新”使用的兼容更新包。更新保留个人工程、歌曲、底片、预设和设置；引擎仍可通过准备窗口下载配置。

操作说明：[弹幕与模板生成](../beta-bullet-control.md)。导入非 RufMaker 工程的注意事项见首页 README。
