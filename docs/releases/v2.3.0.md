# RufMaker 2.3.0

首次下载请选择 **RufMaker-2.3.0-Windows-Portable.zip**，完整解压后打开 `RufMaker.exe`。已有版本可使用软件里的“检测更新”；`RufMaker-2.3.0.zip` 为自动更新包，保留旧版更新器所需的校验方式。

## 复制物件与时间轴剪辑

- 新增“弹幕生成模板 → 复制obj”，支持普通对象、整体对象、发射器和父子分组，保留关键帧及原有行为。默认每50帧生成一轮，间隔0只生成一次。
- 支持上下左右、网格、圆周排列；网格可设间距、像素宽高及旋转。副本可保持、指定、朝向中心、背向中心或沿切线朝向，并使用继承、固定或彩虹配色。每轮最多300份。
- 下栏新增“整理时间轴”，按种类与功能分配轨道；不改变时段、参数、随机结果和执行先后，可撤销。
- 相接片段紧贴显示，接缝用细白线表示。结束帧包含在时段内，例如49帧结束与50帧开始正好相接。
- “拉伸关键帧”可选保持时间、同步、全部缩放或重复填满。默认同步普通关键帧，密集拉镜/特效重复原样式；原周期随工程保存，缩短再增长仍能恢复。动作预设路径继续按参数逐帧重建，其他属性也按所选模式处理。

复制模板是应用预设时建立的共享动画副本，后续修改来源不会自动重做模板；可编辑关联模板卡片来调整所有副本。普通贴图混色需要白色底图；彩虹Cherry可固定副本的彩虹贴图帧。

## 关键帧与事件

- 下栏只显示当前物件的关键帧标记，其他物件的键和属性子行折叠；逐属性选帧、拖动、框选、加删和缓动编辑集中在右栏。
- 右栏关键帧区与参数区之间可拖动分隔条，高度随布局保存；大字号起终点按钮和关键帧行保持完整。修复隐藏页签高度为零时可能出现的分隔条异常。
- 左栏新增“事件”：清除飞行子弹、清除全部弹幕（含整体对象）、所有子弹停速、恢复出生或自定义运动属性。默认执行一帧，拉长后持续执行。
- 事件可明确指定额外原生对象，包含其子类；原生底片缓存不会被这些事件改写，原生效果以F5及导出游戏为准。

本版完成预览与真实GM运行数值对照，覆盖复制位置、分组内随机运动、朝向、颜色、彩虹帧、重复特效，以及原生事件与F5中途启动。个人工程、音乐和底片不包含在发布包里。

详细用法：[复制与时间轴教程](https://github.com/wymcaT/RufMaker/blob/main/docs/copy-and-timeline-editing.md) · [事件预设](https://github.com/wymcaT/RufMaker/blob/main/docs/event-presets.md)。
