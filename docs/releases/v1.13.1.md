# RufMaker 1.13.1

这次加入了音频频谱和对象数量统计，也解决了修改单项属性后撤销时整页重建造成的卡顿。

**首次下载软件：选择 `RufMaker-1.13.1-Windows-Portable.zip`，完整解压后运行 `RufMaker.exe`。**

`RufMaker-1.13.1.zip` 是编辑器“检测更新”使用的兼容更新包。两个 ZIP 都附有 SHA256 校验文件。更新保留个人工程、歌曲、底片、自定义预设和设置。

## 音频与时间轴

- 在音频区域右键，可以切换波形图和频谱图。频谱横轴是时间，纵轴是频率（Hz，对数排列），越亮代表能量越强。第一次分析完整歌曲后会缓存结果。
- 拖动音频区域的底边可以放大频谱；拖动左侧轨道名称区域的底边，可以分别调整轨道或属性行的高度。双击边缘还原，显示方式与高度随布局保存。

## 对象统计

- 右栏新增“对象统计”，同时显示当前预览帧的 obj 总数、GameMaker 对象类型和 RufMaker 来源物件。也可以点击底部状态栏的 obj 数字打开。
- 统计复用预览的演算结果。拖影使用 Draw 绘制，不会每片创建 obj；纯绘制的装饰物件另列。
- 原生工程重新生成底片时会记录原生对象数量。旧底片仍可查看；没有计数数据时，界面会提示重新生成，并明确只显示 RufMaker 部分。普通房间中由原生代码额外生成的实例标为估算。

## 编辑响应

- 普通单项属性的撤销、重做会保留现有控件和滚动位置，只更新变化的值。字段结构或可选项改变时才重建页面。
- 撤销记录和保存使用独立数据快照，减少整工程 JSON 转换；保存时的协议序列化放到后台。
- 房间数据没有变化的保存结果会跳过预览重算，歌曲未变的撤销也不重新载入音频。

升级后请保存并重启编辑器。GameMaker 引擎仍通过“引擎设置”按需下载配置。

使用方法和导入非 RufMaker 工程的注意事项见 [README](https://github.com/wymcaT/RufMaker#readme)。

## English

For a first installation, download **`RufMaker-1.13.1-Windows-Portable.zip`**, extract everything, then run `RufMaker.exe`. The other ZIP is for the in-app updater. Both include SHA256 checksums.

- Right-click the audio area for waveform/spectrogram. Resize audio, timeline and property rows independently; the layout is remembered.
- Object counts show GameMaker types and RufMaker sources for the rendered frame. Regenerate old native recordings to capture their instance counts.
- Scalar undo/redo reuses inspector controls and scroll position. Independent history snapshots, background save serialization and unchanged-room detection reduce editing stalls.

Save your project and restart after updating. See the [English guide](https://github.com/wymcaT/RufMaker/blob/main/docs/README.en.md).
