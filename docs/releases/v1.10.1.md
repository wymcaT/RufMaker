# RufMaker 1.10.1

- 参数支持 `player.x`、`player.y`、两点方向、距离和时间公式，新增 ƒx 公式选择窗口。
- 支持指定范围填充逐帧表达式关键帧；新增持续追踪玩家、限制转角、延迟跟踪和自定义逐帧方向公式。
- 修复预览中地形拼接在旋转、拉镜和缩放时露出细缝的问题。
- 统一房间背景和贴图的像素采样设置，保留贴图原有透明边缘。

## 下载

- 第一次使用：下载 **RufMaker-1.10.1-Windows-Portable.zip**，完整解压后打开 `RufMaker.exe`。
- 已安装用户：可在编辑器内点击“检测更新”。**RufMaker-1.10.1.zip** 是自动更新包。
- 完整便携版包含程序、运行依赖、素材和模板。没有 GameMaker 8.2 时，可在“引擎设置”中一键配置。

项目和个人设置不会随更新包分发。预览读取参考玩家的位置，实际游戏读取真实玩家；原生底片仍保留录制时的画面。
