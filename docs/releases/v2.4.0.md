# RufMaker 2.4.0

首次下载请选择 **RufMaker-2.4.0-Windows-Portable.zip**，完整解压后打开 `RufMaker.exe`。已有版本可使用软件里的“检测更新”；`RufMaker-2.4.0.zip` 供自动更新使用，继续兼容原有 SHA256 校验。

## 时间轴更跟手

- 拖动游标时始终跟随鼠标，黄色虚线预告松手后会吸附的位置，停住鼠标也不会提前吸附。按住 Alt 可隐藏候选并跳过全部吸附。
- 游标可以吸附任意物件的起点、末帧、可见右边缘及属性关键帧，也包括已识别的 GM 原生代码关键帧，无须选中对应物件。
- 移动物件、拉伸左右边界时也能吸附共享游标，多选时保持相对间距；原有边缘吸附仍可关闭。
- 游标按鼠标像素绘制，预览仍使用对应的游戏帧。波形、频谱、刻度和轨道采用独立底图，拖动游标时只重绘覆盖层，减少重复绘制。
- 独立物件不再占据同轨同帧。旧工程重叠内容会自动分配到可用轨道，保留时段、关键帧和执行顺序；拖动覆盖继续裁剪其他片段。

## 右栏可自由排版

- “常规设置”和“关键帧”成为两个可停靠页面，拖动标题可左右、上下排列，或合并为页签；分隔条可以自由调整大小，布局自动保存。
- 物件的小时间条、起终点按钮和帧输入移入关键帧页，随页面一起移动。
- 关键帧的帧数、数值、表达式和缓动放在同页详情区，常规参数保持原来的浏览位置。
- 时间轴、参数区、资源列表和 GML 窗口的原生滚动条统一使用暗色样式，包含动态控件和句柄重建。Windows 10 1903 之前的系统保留原生回退。

## 复制物件实时联动

- “复制obj”默认开启“实时联动来源”，来源的形状、数量、半径、角度、位置和动画变化会同步到副本；默认只建立一组联动副本。
- 网格按每颗成员循环铺满房间，整体中心在屏外也能生效；平移多个格距后仍会补齐，支持旋转网格。
- 修正父级旋转与模板上下文，整体释放为飞行弹幕时保持副本方向、颜色和大小。
- 关闭“实时联动来源”可以继续使用独立模板和重复生成。**旧工程缺少此选项时也默认开启联动**；若想保持旧的独立副本效果，请关闭该选项。单颗飞行弹幕的年龄生成行为继续使用独立模板。
- 每组最多300份，过密时需要增大网格间距。

本版已完成复制语义的预览/真实 GameMaker 数值对照，以及界面交互、重绘和保存迁移检查。密集时间轴测试显示重绘开销减少；实际游戏帧率仍取决于工程内容。
