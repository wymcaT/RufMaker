# RufMaker 2.2.0

首次下载请选择 **RufMaker-2.2.0-Windows-Portable.zip**，完整解压后打开 `RufMaker.exe`。已有版本可使用软件里的“检测更新”；`RufMaker-2.2.0.zip` 为自动更新包。

## 弹幕制作

- 左栏新增五种弹幕生成模板：整体扩散（保持形状/统一速度）、360°随机弹、自机狙、溅射。拖到来源物件上即可持续生成。
- 新弹幕可独立设置寿命模式、销毁过渡、拖影以及年龄行为。随机弹每颗独立取样，方向可填写 `random_range(0,360)`、自定义范围、`choose(...)` 或固定角度。
- 时间轴新增全局变量，支持随机表达式、重复赋值和 `global.变量名` 引用，倒拖与F5中途试玩会恢复之前的逻辑。
- 预览中的重叠物件可通过候选栏选择下层物件或房间实例。

## 动作与剪辑

- 14种动作预设改为编辑路径参数，每帧铺设位置关键帧；绑定时隐藏原始X/Y编辑，可转为手动关键帧。
- 为密集位置关键帧加入预览索引和导出时的二分查找，避免每帧遍历整段路径。
- 拖动期间固定时间轴布局，手中物件不再因重叠跳行。按用户选择，同轨覆盖裁短其他物件，中间覆盖保留前后两段，整次操作可撤销。
- 裁剪保留原始运动、发射、变量赋值和特效时间原点，支持分组、循环片段及生成模板引用。
- 默认开启跨轨道物件边缘吸附，可在“吸附”菜单关闭；同轨物件首尾可直接衔接。
- 优化属性面板滚动、暗色显示、模板双击编辑与撤销体验。

旧版动作需重新拖入一次预设以启用参数编辑；已有手动关键帧不会自动改写。

详细用法：[动作预设与时间轴剪辑](https://github.com/wymcaT/RufMaker/blob/main/docs/motion-timeline-editing.md) · [弹幕生成模板与全局变量](https://github.com/wymcaT/RufMaker/blob/main/docs/generation-presets.md)。
