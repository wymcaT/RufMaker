# 星星复制扩散示例

需要 RufMaker 1.13.5 或更新版本。在编辑器中打开同目录的 `Star Echo.rufmaker`（目录名有数字后缀时，文件名也有相同后缀）。

按空格预览；第 100 帧（2 秒）原星星的每颗成员会额外发射一颗新弹幕，原星星继续移动和旋转。新弹幕按距原中心的距离分配速度，扩散后保持第 100 帧星形的比例。拖到第 150 帧可对照两份星形。F5 可进入真实游戏；导出游戏生成可独立游玩的 EXE 和 Data。

示例有两条物件：

- **原星星 · 移动并保留**：使用引擎原 `star2` 轮廓，60 颗弹幕。起点 `(230,190)`，通过关键帧移动、旋转；第 100 帧中心为 `(287.5,215)`。释放队形保持关闭。
- **扩散弹模板 · 来源距离 × 0.02**：仅作生成模板，开始/结束均为第 0 帧，只发射 1 颗弹幕。生命周期为 200 帧；弹幕年龄 0 时一次性设置速度。

弹速行为公式：

```text
point_distance(x,y,source.x,source.y)*0.02
```

`x/y` 是新弹幕自身的位置；`source.x/source.y` 是触发生成时，直接来源物件中心的世界坐标快照。它自动计入移动、父分组和生成实例的变换，不需要填写 `(400,304)`。原来源之后移动或消失，这个出生快照仍保留。飞行弹幕再生成模板时，新的来源中心是母弹当时的位置。

在原星星的“物件生成行为…”中：生成位置为“各颗弹幕”，开始年龄 100，重复间隔 0，每颗延迟 0，继承母体方向开启，生成后销毁母体关闭。新弹幕的飞行方式为直线，没有后续加速或转向。

可以移动原星星或修改它的关键帧，再预览第 100 帧之后；扩散中心会自动跟随新的生成位置。修改 `0.02` 可改变扩散速度；将重复间隔改为正数可连续生成多批扩散弹。

尚未生成模板时，参数公式预览中的来源参考值使用该物件的基础 X/Y。要查看实际来源中心下的结果，请预览触发生成后的弹幕。开始年龄按来源物件自己的开始帧计算。

重新创建一份独立示例：在仓库根目录运行 `runtime/node.exe tools/examples/create-star-echo.mjs`。不会覆盖已有同名工程。
