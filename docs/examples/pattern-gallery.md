# 弹幕制作范例：11 个分章节教程

需要 RufMaker 1.13.8 或更新版本；推荐 1.13.9，支持把物件、生成规则与模板卡片收在同轨生成组中。打开同目录的 `.rufmaker` 文件；重建时若已有同名目录，新工程和文件名都会带数字后缀。旧的 Star Echo 和旧版范例会保留。

这是可编辑的真实工程：参数、关键帧、生成模板、年龄行为都能在 UI 中查看和修改，可以 F5 试玩或导出独立游戏。每章 8 秒，共 88 秒，默认 50 FPS。歌曲沿用引擎模板的示例曲，仅用作预览伴奏；本教程按章节讲解，没有针对该曲逐拍编排。

## 先这样看

1. 用右侧或下方的帧数输入定位到表中的“推荐查看帧”。按空格播放，观察这一章的动作；F5 可以从当前位置进入游戏。
2. 在时间轴选名字带章节编号的主物件。原工程 0 号轨道放主物件，1 号放辅助物件。1.13.9 会把生成规则和引用模板自动收在来源轨道下面，模板原来的单独轨道隐藏；未引用模板仍显示为宽卡片。
3. 主物件右键“物件生成行为…”查看整件的生成规则；发射器右键“弹幕行为…”查看每颗子弹出生后的动作。生成规则中的模板名对应另一条物件。
4. 展开物件查看属性关键帧；菱形标记只控制所在属性。没有关键帧时直接改数值即可改整件的固定值。
5. 复制到自己的耐久时，把来源及引用模板一起多选复制，或存成自定义预设。Ctrl+V 会以播放头对齐所选物件的最早起点，内部的时间关系保持不变。

展开来源物件后，带 **↗** 的行显示生成规则在歌曲中的触发时刻，已计入逐成员延迟和重复；单击定位，双击编辑对应规则。编辑窗口的“首次触发歌曲帧”可直接填写绝对时间。飞行弹幕生成行显示按配置寿命推算的计划时刻；提前越界或销毁会停止实际生成。

规则下面的模板卡片显示完整名称、单次/局部动画、帧范围和关键帧数量。单击改模板参数；双击展开原来的关键帧，并把播放头切到模板局部起点，适合继续编辑动画。模板共用时修改会影响所有引用。拖动来源物件时，这些引用会跟着显示在新位置，模板保存的局部时间不变。

模板卡片显示的是动作定义及其局部时间，放在第 0 帧不表示游戏第 0 帧就会出现。它被生成时才从自己的局部起点播放。模板内更深层的生成也随实例时钟平移，不能只靠模板长条推断歌曲位置。

单色示例使用 `sprCherryWhite` 再设置颜色，彩虹队形使用 `sprrainbowcherry`。颜色参数会与贴图本来的颜色相乘，选择白色底图更方便调配任意颜色。

## 01：每秒复制一份星星，保持扩散形状

选“01 周期星星扩散 · 原星星保留”。轮廓使用引擎原 `star2`，数量 60，中心从 `(280,215)` 移到 `(520,215)`，队形同时旋转。

右键“物件生成行为…”：

- 模板：`模板 · 01 距来源中心距离 × 0.018`。
- 开始年龄 50；重复间隔 50；持续帧数 200；每颗延迟 0。
- 生成位置“各颗弹幕”，继承母体方向开启，生成后销毁母体关闭。
- 初始生成方向和每颗方向递增都为 0。
- “继承出生贴图与颜色”和“继承母体大小”均开启；新副本与母体同样大，保存发射瞬间各成员的彩虹颜色，之后不会跟着原星星变色。

这样会在歌曲第 50、100、150、200、250 帧各生成一批，共 5 批。模板自身只在局部第 0 帧发射一次，每颗新弹幕的速度行为也在年龄 0 执行一次：

```text
point_distance(x,y,source.x,source.y)*0.018
```

新弹离生成时的整体中心越远，速度越快，因此保留那一刻星星的比例。`source.x/y` 是出生时捕获的来源中心，原星星随后继续移动不影响已生成的副本。可改乘数控制扩散速度，改重复间隔控制节奏。模板寿命 120 帧，最后 15 帧缩小并透明。

## 02：星星成员挨个发射，而且循环

本章星星有 30 名成员。模板是普通单发，速度固定 3，没有按距离计算弹速的行为。

主物件生成设置：各颗弹幕；开始年龄 0；每颗延迟 2；重复间隔 70；持续帧数 140；不继承母体方向；初始方向 -90 度；每颗方向递增 12 度；不销毁母体。出生贴图/颜色和大小继承开启，新弹与生成它的成员大小、彩虹帧一致。

对编号 `i`，第 `r` 轮的发射时刻和方向是：

```text
歌曲帧 = 400 + i*2 + r*70    （i=0..29，r=0..2）
方向   = -90 + i*12         （GM 角度：0 向右，90 向上）
速度   = 3
```

每轮持续发射 58 帧，再等 12 帧进入下一轮，共三轮。重复间隔应大于 `(成员数-1)×每颗延迟`，才会出现清楚的轮次；设得更短会让两轮交叠。想持续循环，把持续帧数设为 0，并拉长原星星的结束时间。成员方向按编号分配，每轮复用同一组方向。

## 03：一颗移动弹，每隔 n 帧原地留一颗弹

“03 移动母弹”只发射一颗，速度 2.5、寿命 240。飞行方式“逐帧方向表达式”为：

```text
25*sin(age/25)
```

这会让行进方向轻轻左右摆动。这里的 `age` 是母弹出生后的年龄，不是歌曲帧。

打开母弹的“弹幕行为…”，生成模板设置为：开始 0、每 6 帧重复、持续 234、模板 `03 静止留点`、不继承方向、不销毁母体。留点模板只发一颗，**速度 0**，寿命 100，最后 20 帧缩小淡出。

因此每个点都留在生成时的世界坐标，母弹继续前进。这些点是真实、有碰撞的弹幕，能在对象统计里看到；拖影只是绘制。想画连续一点，降低重复间隔或增大留点缩放；直线匀速情况下，相邻点距离约为“母弹速度 × 间隔”。想让整条线保留更久，增加留点寿命。

## 04：两组反向螺旋

两个发射器同在 `(400,240)`，各发 3 路，路间隔 120 度，每 5 帧发射，速度 2.4。角度表达式分别是：

```text
age*2.1
60-age*2.1
```

发射角随时间旋转，所以后来的弹幕与前一批错开，组成螺旋。飞出去的每颗子弹仍走直线。增大 2.1 会让螺旋更紧，降低发射间隔会更密；可先只启用一条物件，理解单组，再打开另一组。

## 05：移动发射点的五路自机狙

X 用关键帧从 180 移到 620；Y 为 105。发射朝向选“扇形方向”，数量 5、路间隔 14 度、间隔 30、速度 2.8。角度表达式：

```text
point_direction(x,y,player.x,player.y)
```

每次出生时重新瞄准，飞出后不再追踪。预览参考玩家在 `(400,536)`；勾选“编辑试玩玩家”移动参考点可查看不同结果。F5 使用真实玩家。想做持续跟踪，把跟踪加到“弹幕飞行”；只修改发射器角度不会让旧弹转弯。

## 06：固定种子的散雨

生成形状“直线”，宽度 700，每轮 12 颗、间隔 30。从上方向下发射：角度 `random_range(258,282)`，速度 `random_range(1.6,2.8)`，中心坐标也有小幅随机扰动。

工程固定种子为 24681357，取样范围是逐颗弹幕。拖回同一帧能重现同一阵雨；按“重新随机”可以整体换一版。想在每次游玩变化，去工程设置开启“每次游玩随机”。先限制角度与速度范围，再增加密度，便于控制可读性。

本章还开启“波次随机颜色”，颜色公式为 `choose("#A0E878","#6DE8FF","#FFC65C")`，同一波共用颜色。“每颗独立配色”开启后逐颗选色。也可填 `random(360)` 随机色相，或 `choose(0,120,240)` 选几个色相，出生后保持不变。模板生成规则中的“波次颜色公式”则能让整个生成批次共用一个随机结果；留空表示保留模板或继承的颜色。

颜色公式改变贴图的混色，使用白色底图才能任意着色；给彩虹贴图混色不会把原本不同颜色都变成同一个色。要保留彩虹成员出生时的颜色，请使用出生外观继承。

## 07：先停住，再瞄准冲刺

发射器每轮 12 路，间隔 60，基础速度 3.5。年龄行为依次是：

| 弹幕年龄 | 行为 |
| --- | --- |
| 0～25 | 弹速 3.5 → 0，power-out |
| 25～45 | 保持静止 |
| 45 | 一次性瞄准玩家 |
| 50～75 | 弹速 0 → 5，power-in |

每批的年龄时钟独立，后面的弹幕会在前面的弹幕冲刺时停住。不要把歌曲第 45 帧当成这里的年龄 45。可以加长停顿帮助玩家读招；瞄准之后等 5 帧再启动，也给了玩家反应窗口。

## 08：母弹走一段，再变为一圈弹

母弹每轮三颗，飞行年龄 45 时生成 `08 14 路开花环`，并勾选“生成后销毁母体”。母弹会缩小淡出，环弹独立飞行。

环模板开始/结束都为 0，数量 14、发射朝向“扇形方向”、相邻路间隔 `360/14`、速度 2.2。开始帧与结束帧相同确保只发一轮；“扇形方向”会应用路间隔。改数量时一起改间隔，才能均匀覆盖整圈。

## 09：圆环先长大，再沿切线散开

来源每 75 帧生成一次整体圆环模板，共三次。模板局部第 0～35 帧，半径从 15 增到 90；局部第 45 帧释放，方向“沿切线”、速度 2.8、释放后寿命 100。模板的 X/Y 均为 0，生成时以来源位置为锚点。

释放前所有成员跟随整体关键帧，释放后各自飞行。切线方向与从中心向外相差 90 度，视觉上形成散开的旋转轮廓。试着切成“径向散开”对比，再给半径或朝向换缓动。

## 10：用两条阵列拼出移动缺口弹墙

这里缺口实际左右摆动。两条水平阵列共同组成一排，分别覆盖缺口左边和右边，每侧 10 颗。两侧都向下，速度 3.6，间隔 35，Y=60。令缺口中心：

```text
g = 400 + 200*sin(age/35)
```

缺口宽度 140，所以左边界为 `g-70`，右边界为 `g+70`。左侧阵列中心 X=`165+100*sin(age/35)`、宽度=`330+200*sin(age/35)`；右侧中心 X=`635+100*sin(age/35)`、宽度=`330-200*sin(age/35)`。

每一排出生后沿直线下降，保留出生时的缺口位置，后续排才用新的位置。这是在空间里画出可追踪的通道；预览时观察连续几排的缺口，而不是只看顶端发射点。减小摆幅或增大周期，可降低通道移动速度。

## 11：原 heart 脚本的心形波纹

每 90 帧生成一层整体心形，共三层。轮廓使用提供的引擎原 `heart`，48 个成员；模板局部半径 0 帧为 12、30 帧为 80、130 帧为 110。透明度在 0～20 帧从 0 到 1，100～130 帧从 1 到 0。

这里的消失由整件透明度关键帧控制，因为成员始终在队形里；“弹幕寿命”的销毁过渡用于发射后或释放后的独立弹幕。想改为发射心形子弹，可以沿用第 01 章的“各颗弹幕 + 距来源距离弹速”方法。

## 参考与进一步练习

本工程按现有编辑能力制作了上述范例，心形和星星沿用随库原始引擎脚本。自机狙、螺旋、环与扇形是可组合的基础结构，可以先减少数量、放慢速度，再叠加节奏。

- [Sparen：发射频率与速度](https://sparen.github.io/ph3tutorials/ddsga1.html)：发射密度的基本关系。
- [Sparen：固定、随机与瞄准角](https://sparen.github.io/ph3tutorials/ddsga2.html)：三种角度来源的设计讨论。
- [Sparen：环、扇形、弹墙与弹列](https://sparen.github.io/ph3tutorials/ddsga3.html)：组合结构与可交互演示，可用于对照第 04、05、08、10 章。

要重建新的可编辑工程，在仓库根目录运行：

```powershell
.\runtime\node.exe tools/examples/create-pattern-gallery.mjs
```

已有同名工程时自动加后缀。分享工程时携带 `.rufmaker` 与旁边的 `GameMaker.gm82/`；分享独立游戏时携带整个 build/release 文件夹。它是制作教程，实际关卡的难度、地形与歌曲节奏需要结合自己的耐久调整。
