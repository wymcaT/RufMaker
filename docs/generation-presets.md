# 弹幕生成模板与全局变量

前五种模板需要 RufMaker 2.1.0；“复制obj”需要2.3.0，详见[复制与时间轴教程](copy-and-timeline-editing.md)。已有工程可以直接打开；新增功能保存在工程里，预览和导出游戏都会执行。

## 拖一下就循环发射

左栏点 **预设 → 弹幕生成模板**，把需要的类型拖到预览中的来源物件，或时间轴上的物件长条。也可以先选中物件，再双击模板。

软件会自动创建发射模板、绑定生成行为，并打开右侧的“行为”页。默认从来源出现时开始，每 **25 帧**生成一次；50 FPS 下就是每半秒一次。持续时间为 0 表示不限制重复次数，实际到来源的结束时间或销毁时停止。已经生成的弹幕会继续自己的运动和寿命，来源本身保留。

“复制obj”默认每50帧复制整个物件或分组，间隔0为一次；它的排列、朝向和颜色在同一“行为”页设置。

右栏直接修改 **发射间隔、首次延迟、速度、每次数量、寿命模式**。新弹幕独立支持固定寿命、出屏幕销毁、出视野销毁，以及缩小/淡出等销毁过渡；“新弹幕拖影”分组可选透明、缩小、变不透明或自定义衰减/漂移。拖影始终画在弹幕本体后面。

点击上方 **“新弹幕行为…”**，直接编辑新弹幕出生后的减速、转向、瞄准、加速、分裂或继续生成等年龄行为。编辑完成仍选中原来源；后代继续生成时默认允许到第4代，复杂组合仍可调整代数限制。

复杂的偏移、成员筛选、颜色和大小继承等生成设置仍在“展开编辑”里。生成模板自动收在来源的同轨生成组中；拖动来源、复制或存为自定义预设时，模板和引用也会一起保留。

| 模板 | 效果和常用参数 |
| --- | --- |
| 整体扩散 · 保持形状 | 拖到整体对象上。每名成员在当前位置额外发射一颗新弹，方向从整体中心向外；越远的成员速度越快，保留生成瞬间的形状比例。速度框表示“距中心100像素处”的弹速，例如填3，距中心50像素的成员速度为1.5。 |
| 整体扩散 · 统一速度 | 同样从各成员当前位置发射，方向从整体中心向外，但每颗速度相同，所以内外层的形状会逐渐变化。 |
| 360° 随机弹 | 从来源中心发射一批随机方向弹。每颗方向独立、每轮重新采样，可改数量和速度。 |
| 对玩家自机狙 | 从来源位置向发射瞬间的玩家开火，每颗弹幕在实际出生时重新瞄准，包含逐颗延迟。默认单发；可调整方向偏移。已发出的弹幕沿出生方向飞行，不会持续追踪玩家；要跟随玩家转向，另选每帧追踪或限速追踪。 |
| 溅射弹幕 | 从来源中心释放完整一圈。数量为n时，相邻方向间隔为360/n度；可选固定方向、每轮重新随机方向、每轮递增角度。 |
| 区域内随机生成 | 按间隔在指定矩形内部随机生成弹幕，每颗位置独立；速度和方向可填固定数值或随机公式，支持出生淡入和三种寿命模式。 |

### 区域内随机生成

把左栏的“区域内随机生成”拖到来源物件上，在右栏“行为”页设置：

- **发射间隔 / 帧**：例如5表示每5帧生成一次，“每次发射数量”控制每次生成几颗。默认在来源物件的整个生命周期重复，不会因为来源发射了多少颗弹幕而额外倍增。
- **区域中心 X/Y、区域宽度/高度**：定义矩形。默认覆盖当前房间；选中来源时，预览会用青色虚线框显示区域。默认使用房间坐标，即使来源移到房间外也保持该区域；开启“区域跟随来源”后，中心改为相对来源的偏移。
- **新弹幕速度**：固定数值，或通过左侧公式按钮设置 `random_range(2,5)`、`choose(2,3,5)`。
- **新弹幕方向 / 度或表达式**：例如 `270` 向下，`random_range(0,360)` 为每颗随机方向，`choose(225,270,315)` 从三个方向选择。0度向右，90度向上。
- **出生淡入、淡入帧数**：开启后从透明渐显，不改变运动速度。寿命仍从出生帧计数；可与销毁淡出一起使用。
- **寿命模式**：固定帧数、出屏幕（房间边界）销毁、出视野（游戏镜头）销毁。出界余量和销毁过渡沿用其他模板。

例如房间顶部下落弹雨：中心设为 `(400,40)`，宽800、高80，间隔5、每次3颗，速度 `random_range(2,5)`、方向270，寿命选“出屏幕销毁”。

新建弹幕及生成模板默认混色为白色；已保存的颜色不改。需要复制来源外观时仍可主动勾选“继承出生贴图与颜色”。Cherry勾选“彩虹”后会出现“随机彩虹颜色”：每颗独立选择彩虹贴图的一帧，之后保持；同时开启动态色彩时从随机初始颜色继续变化。随机结果沿用工程种子，倒拖不会改变，“重新随机”可重新取样。
| 复制obj | 复制来源及其子物件的动画与行为，支持上下左右、网格、圆周排列，以及朝向中心和整圈彩虹。默认复制整个发射器，可切换为逐颗飞行弹幕触发。 |

“保持形状”使用的公式为 `point_distance(x,y,source.x,source.y)*speed/100`。`source.x/y` 是生成时来源中心的世界坐标快照，来源继续移动后不会拉扯已生成的新弹。星星和心形仍使用原引擎的 `star2`、`heart` 轮廓。

拖到普通对象、整体对象或分组上，按**时间轴物件本体**的生命周期循环。拖到弹幕发射器上，默认让**发出的每颗弹幕**在飞行过程中按自身年龄循环，生成位置跟随母弹；可以在右栏“生成来源”切换为“发射器本体”。

### 溅射的两个常用做法

- **每轮换一个随机初相位**：选择“每轮重新随机方向”。同一轮仍是均匀的一圈，只是整圈的朝向改变。
- **连续旋转的圆环**：选择“每轮递增角度”，初始方向填0，每轮递增填15。各轮初始方向为0、15、30、45……，每轮内部仍均匀分布。

### 自己填写随机弹方向

360°随机弹的右栏有 **“新弹幕方向 / 度或表达式”**。默认 `random_range(0,360)`；同一轮的每颗弹幕都独立取样，同一帧由不同来源成员发射的弹幕也分别取样。

- `random_range(30,150)`：每颗在30到150度之间随机。
- `choose(0,90,180,270)`：每颗从四个方向中随机选一个。
- `45`：固定向45度发射。

0度向右，90度向上。方向在出生时确定；需要飞行中转向或跟踪玩家时，使用“新弹幕行为…”。固定种子下倒拖、保存再打开和F5历史重放仍可复现；点击“重新随机”会更换结果。

### 预览中有多个物件重叠

点按重叠位置，松开鼠标后会出现候选小栏，显示物件名、轨道编号和类型；房间内手动摆放的实例也能选。选择条目后再编辑，按Esc或点空白可取消。Ctrl/Shift选择可保留多选；按住鼠标直接拖动时优先移动当前已选物件，仍可正常编辑重叠区域。

## 在时间轴定义共享变量

顶栏 **＋ 添加 → 添加全局变量**，或右键时间轴空白处添加。变量是一条可移动、复制的时间轴物件。

右栏设置：

- **变量名**：例如 `phase`。使用英文字母、数字和下划线；软件统一为小写。`rf_` 前缀保留给内部脚本。
- **赋值表达式**：例如 `random(360)`、`choose(0,90,180,270)`、`floor(random_range(1,6))`。
- **赋值前默认值**：时间轴还没走到首次赋值时的值；同名变量的第一个声明提供初值。
- **开始帧**：第一次赋值的歌曲帧。
- **重复赋值间隔**：0表示只赋值一次；例如25表示每25帧重新计算，直到结束帧（含边界）。

计算后会保留结果，直到下一次赋值；结束帧之后也会保留。多个同名变量物件可以在不同时间重新赋值。若在同一帧触发，按工程执行顺序依次赋值，最后一个结果生效；所有变量赋值都先于该帧的弹幕生成执行。未整理的工程沿用轨道顺序，“整理时间轴”会保留整理前的执行顺序。

其他物件的参数开启表达式后，用 **`global.phase`** 引用。例如：

```text
方向：global.phase
速度：2 + global.level * 0.5
数量：floor(global.count)
```

变量的表达式也能读取其他变量或自身的上一次值：

```text
变量 phase 的表达式：global.phase + 15
变量 distance 的表达式：point_distance(400,304,player.x,player.y)
```

除了 random、random_range、choose、floor，也支持现有的 point_direction、point_distance、sin、cos、min、max、clamp、lerp 等基础函数与四则运算。公式示例选择框可以直接填入常用写法。

### 示例：每半秒改变整组弹幕的方向

1. 新增变量 `phase`，开始帧0、结束帧500，表达式 `random(360)`，重复间隔25。
2. 在发射器的方向参数里填写 `global.phase`。
3. 其他需要同步转向的发射器也引用同一个变量。

每次赋值只采样一次，因此这些物件会共享同一份随机结果。预览倒拖会重新得到之前的结果；“重新随机”会用新种子重建整段历史。F5 从中途启动，也会先执行之前的赋值历史。

重命名变量会更新参数公式中的引用；复制、跨工程自定义预设会携带引用的变量。名称冲突时自动另取名字并更新复制内容的引用。手写 GML 中的引用不自动改写，原生代码可直接读取 `global.phase`。
