# 右键菜单与属性分类

物件、属性和关键帧各自提供当前操作需要的菜单。

- **物件右键**：编辑属性、编辑关键帧、复制、粘贴、删除。“更多物件操作”保留行为、预设、启用/禁用、仅预览隐藏、循环片段和移动轨道。“轨道与组”管理轨道所属组及空轨道。
- **属性右键**：为当前属性加关键帧、编辑公式、清除该属性的关键帧，或打开关键帧页。
- **关键帧右键**：复制、删除、缓动、选择与粘贴关键帧。清除某一属性的键会保留当前数值，其他属性的键不变。
- **空白处右键**：添加物件或事件，管理轨道。添加菜单与顶栏共用内容。

撤销、重做和常用快捷键继续使用顶栏或键盘，不再重复摆进每个右键菜单。

## 属性配置

发射间隔、数量、弹速和阵列统一在“发射”；波次随机颜色归入“外观”。标签、旧工程变换父级、模板用途、逐颗递增和随机取样范围放在默认折叠的“高级设置”。行为统一在“行为”页编辑。

未使用的参数按模式隐藏，切回对应模式时重新显示，数值仍随工程保存：

- 转转棒根据端点模式展示坐标或棒长；开启滚动后展示滚动速度。
- 直线阵列不显示高度、圆弧角度或波形周期；正弦、椭圆等显示各自使用的参数。
- Power 指数与 ExpSin 周期只在轨道或其关键帧使用对应缓动时显示。
- 静态彩虹不显示流动速度；启用动态色彩后出现。
- 特效只显示其使用的遮罩颜色、方向和帧混合参数。
- 未设置释放帧时隐藏释放方向和保形选项；出生/释放弹速仍可设置。

已有关键帧或公式的动画属性继续显示，方便检查和清理。动作预设使用“速度 / 圈每秒”和持续时间调整运动，不再并列展示同一含义的圈数输入；原有运动圈数数据仍保留。

分类展开状态和滚动位置沿用原有工作区偏好，参数编辑、拖动步长和撤销方式不变。这次只调整编辑入口，没有改变游戏计算或导出格式。
