# 参考耐久视频：功能缺口与制作顺序

参考文件：`558905419-1-208.mp4`，时长约 **3 分 28 秒**。时间均为视频时间。观察覆盖全片，并对代表段落抽取相隔 0.6 秒的连续画面，区分静态造型和运动变化。

## 当前工具能做到什么

现有发射器能做匀速环形、扇形、旋转发射；转转棒能做等距直线、旋转直线和沿线滚动。已有独立属性关键帧、缓动、速度/加速度、圆周运动、彩虹 Cherry、拖影及若干全屏特效。复制物件组可保留全部关键帧。复杂逻辑可以写 GML，并导出真实 GameMaker 游戏。

这些基础可覆盖视频中的部分直线、旋转线、放射与颜色效果。要主要依靠界面制作整段耐久，仍有下面的缺口。

## 推荐制作顺序

### 第一批：做出主要弹幕形状

1. **形状与曲线生成器**：圆环、椭圆、弧线、贝塞尔和正弦曲线；可视化控制点；固定数量或固定间距布弹；路径进度、缺口和滚动。
2. **分组和阵列**：父级控制位置、角度、缩放，子物件使用局部坐标；沿直线、圆周、网格复制；参数可引用子弹序号 `i`、总数 `n`、相位和组内时间。
3. **子弹出生后的行为编辑**：单独的“子弹年龄”时间轴，分阶段设置加减速、转向、绕心、收束、停顿后发射、寿命与清除，并配置缓动。目前发射器的弹速/方向主要在出生时采样，单纯给发射器加关键帧不能完整替代这项能力。

这三项直接对应视频中反复出现的圆环、S 形链、弯曲放射与漏斗，应优先于继续增加全屏特效。

### 第二批：做出演出和关卡切换

4. **游戏内镜头轨道**：位置、旋转、缩放、视口与跟随目标；可以只影响游戏世界。本次 Ctrl+滚轮属于编辑器取景，游戏内镜头需独立实现。
5. **背景与合成图层**：图片/动画背景、层级、混合、色彩、透明度、遮罩、镜像、发光/描边；可只作用于某组弹幕。
6. **关卡与事件轨道**：带碰撞的平台移动/旋转、显隐和碰撞开关，玩家出现/传送、清弹、背景换段、检查点。视频中具体物理机制仍需结合游戏验证，界面先支持明确的事件与碰撞控制。

### 第三批：让长耐久更容易修改和调试

7. **音乐与片段工作流**：拍点/段落标记、节拍吸附、循环播放选区、片段嵌套、整体拉长缩短、重复次数和偏移；拍点及 BPM 应由音频标定。
8. **统一的确定性预览**：同一套序号、随机种子、运动与关键帧规则，配合阶段快照加速任意定位。手写 GML 的历史副作用和依赖玩家位置的弹幕，需要原生试玩或录制的玩家轨迹辅助回放。
9. **密集场景性能与可读性**：批量绘制、实例复用、拖影预算、按层隐藏/独奏、运动轨迹及碰撞框；显示弹幕数和渲染耗时。文件编码约 30 FPS，不能据此推断原游戏运行帧率。

## 下一轮最建议做的内容

先实现 **圆环/曲线生成器 → 分组局部坐标 → 子弹年龄行为**，再做镜头与背景图层。每项都应同步生成 GameMaker 代码，并能在同一时间点重建预览。

参考视频和抽帧仅用于本地分析，整段视频不随代码上传。
