# 动作预设与时间轴剪辑

2.3.0新增了“整理时间轴”、片段白色接线和拉伸关键帧模式，详见[复制与时间轴教程](copy-and-timeline-editing.md)。默认同步关键帧，密集拉镜/特效重复原样式填满；也能保持原时间或全部按比例缩放。

## 关键帧在右栏编辑

下栏用于安排物件的时段和轨道，仅显示当前选中物件的关键帧标记，所有属性子行保持隐藏。2.4.0在右栏使用独立“关键帧”页面，按属性分行，可选帧、拖动和框选；只列出已经有关键帧的属性。选中一帧后，在同页详情区编辑帧、数值和缓动。◇ / ◆ 仍在原参数旁开启或关闭动画。

下栏点击标记或双击普通物件可打开关键帧页。◀ / ▶ 跳到当前属性的前后关键帧，◆ 加键，− 删除所选，“适应”显示整个物件时段，Ctrl+滚轮缩放。预览与两个时间区共用播放头。自动采样的动作预设 X/Y 不铺进这里，继续通过动作预设参数修改。

拖动页面标题可以把关键帧与常规设置排列为上下、左右或合并页签。分隔条调整大小，布局和尺寸会保存；关键帧页内另有列表/详情分隔条。操作见[右栏排版说明](inspector-layout.md)。

2.4.0的“吸附”面板提供 **游标吸附物件与关键帧** 与 **物件吸附边缘与游标**，默认开启。游标可对齐所有歌曲物件的起点、末帧、右边缘及关键帧，也识别GM原生代码帧；不需要选中该物件。拖动游标期间始终自由定位，黄色虚线预告松手会吸附的位置；鼠标停住也不提前吸附，只有松手才采用目标。下栏、右栏时间尺和右栏进度条共用此行为，进度条标题中的箭头会显示候选帧。时间尺游标按鼠标像素绘制，预览仍使用对应游戏帧。按住Alt隐藏候选并跳过所有吸附，停止后也保留自由定位的位置。

移动物件的左右边缘、拉伸起点或终点，均能对齐共享游标。多选时统一移动/拉伸，间距保持；末帧199对应可见右边缘200，吸附后能与从200开始的下一件贴紧。原有吸附开关可关闭这些行为；输入精确帧数、逐帧和左右键导航不受影响。

## 调整动作预设

在左栏选择 **预设 → 动作预设**，拖到物件或拉镜上。右栏的 **动作预设参数** 会显示对应路径的设置：

- 抛物线：起点、终点和经过的峰。
- 圆周：中心、半径、圈数与初相角；圈数可填负数反向旋转。
- 水平/垂直往返：起点、振幅、往返次数与初相角。
- 螺旋：中心、起始半径、结束半径、圈数与初相角。
- 八字、S形、漂浮：对应的中心或起终点、振幅与次数。
- 滑入、滑出、下坠、斜向穿越：起终点与路径缓动；停顿冲刺另有停顿占比。

修改这些参数后，会重新生成该物件时段内**每一帧的 X/Y 关键帧**。相邻帧之间使用线性连接，曲线和缓动已包含在采样值中，避免在稀疏节点处反复减速。角度、大小、颜色等其他属性保留自己的关键帧。

绑定期间，右栏不再显示原始 X/Y 输入，自动生成的位置关键帧也不接受拖动或额外插键。拖动画布里的物件会整体平移这条路径。需要手动改位置关键帧时，将“动作预设”改为 **手动关键帧**；已生成的关键帧会保留。

改变物件长度会按新长度重新铺键；复制、保存工程或存为自定义预设会保留路径参数。跨帧率导入预设会重新按目标帧率铺键。

旧版已经应用的动作没有记录预设名称与参数，因此不会自动猜测或改写。重新拖入一次动作预设，即可启用这一套编辑方式。

## 拖动和覆盖

2.4.0不再允许独立物件在同一轨道的同一帧重叠。旧工程的重叠物件会自动移到其他轨道，时间、父子关系和执行顺序保留；新增、粘贴或数值编辑产生的冲突也会分配到其他轨道。生成组内的模板仍跟随来源显示。

手中的物件随鼠标移动，不会因重叠自动换到其他轨道。只有主动上下拖动才会改变轨道。松开鼠标时，**同轨道其他物件被覆盖的时段会被裁掉**：

- 盖住左端或右端：裁短那一端。
- 盖住中间：保留前、后两段。
- 完全盖住：从时间轴移除那一段。

没有覆盖到的部分保持运动进度、发射节奏、关键帧和效果进度。分组的子物件随对应部分保留，共用的生成模板定义也会保留。来源停止生成后，已经发出的弹幕仍按自己的寿命和行为继续运行。

一次拖动及其造成的裁剪可以用一次 **Ctrl+Z** 一起恢复，选中仍保留在手中的物件上。跨轨道的时间重叠不会裁剪其他轨道。

## 物件边缘吸附

下栏 **吸附 → 物件边缘吸附（跨轨道）** 默认开启，可以关闭，设置会随界面预设保存。按住 **Alt** 可临时忽略吸附。

拖动或拉伸物件时，靠近其他轨道物件的起止位置会自动对齐，并显示黄色吸附线。同轨道靠近其他物件末尾时，会优先吸到它结束的下一帧，直接衔接；例如前一段结束于100帧，后一段从101帧开始，避免边界帧重复执行。
