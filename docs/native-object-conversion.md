# 原生对象转换与按需属性

## 把 GM 对象变成可编辑物件

在左栏 **资源 → 对象** 中右键一个原生 GM 对象，选择 **转换为可编辑物件…**。

编辑器会先检查，显示识别结果，再让你添加到时间轴。成功时创建一个独立的单发弹幕来源：从当前游标开始，初始片段长约 5 秒，每次只生成一颗，默认出房间销毁。位置、弹速、方向、外观、物理和动画可以继续在右栏编辑，或用关键帧控制后续生成的弹幕。修改发射间隔可以让它反复生成。

转换按标准 RufMaker 弹幕处理碰撞，适合将简单运动对象作为弹幕素材使用。原 GM 对象、GML 和房间实例都保留；转换后的物件是独立副本，后续修改原对象不会自动覆盖它。

当前可识别：

- 对象贴图、绘制深度。
- Create 中直接设置的坐标、速度、方向、水平/垂直速度、重力、重力方向、阻力。
- 贴图角度、透明度、颜色、等比缩放、起始动画帧、动画速度。
- 对应的“设置变量”“设置速度方向”“换贴图”原生参数动作。
- 可由现有表达式系统执行的数学和 `random`、`random_range`、`choose` 等随机初始化。支持用分号或换行分隔赋值。

Step、Draw、闹钟、碰撞等自定义事件，以及继承、实心/持久控制器、独立蒙版、不等比缩放等，暂时不能自动等价转换。窗口会列出原因，并提供 **保留为原生片段**；原生片段仍由 GM 执行全部原事件，可按空格生成动态预览、用 F5 试玩。

## 物件属性按需添加

在左栏 **预设 → 物件属性** 拖入以下模块。新建物件不会默认展开这些参数；收回模块只收起界面，参数效果仍保留。

**弹幕物理**：适用于发射器的子弹、以及整体对象散开后的成员。可设飞行加速度、阻力、重力及重力方向。出生帧不先移动；之后每帧依次应用加速度、阻力、转向、重力，再移动。阻力把速度减到零，不会倒推。重力方向使用 GM 角度，270° 向下。

例如：弹速 `4`、方向 `60`、重力 `0.15`、重力方向 `270`，可以做出向右上飞出后落下的弹幕。参数在每颗出生时读取，支持随机表达式和属性关键帧。整体对象未散开时仍由形状与运动预设控制；运动重设/公转事件会接管其后续运动。

**贴图动画**：可设起始贴图帧、动画速度和动画延迟。帧从 0 开始，速度 `0` 固定、`0.25` 每四个逻辑帧前进一帧、负值反向循环。转换原生对象时自动保留 GM 的一帧启动延迟；手工物件默认延迟为 0。

彩虹开启时，由彩虹系统控制贴图帧。继承当前外观生成新弹幕、或按组复制弹幕时，仍按既有规则保留发射瞬间的贴图与颜色。

保存、撤销、复制、自定义预设和导出均携带新参数。预览和真实游戏使用同一套取样顺序；片段变速会同时缩放物理量、动画速度及延迟。
