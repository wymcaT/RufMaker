# 复制 obj 与时间轴整理

本页功能需要 RufMaker 2.3.0，预览与导出游戏均支持复制物件。

## 复制整个物件

在左栏选择 **预设 → 弹幕生成模板 → 复制obj**，拖到物件上；也可以先选中物件，再双击这个模板。普通对象、整体对象、发射器和父子分组均可作为来源。

软件会把来源及其子物件复制成一个可编辑模板，并在来源的“行为”页添加复制规则。副本包含原有关键帧和行为，从模板的动画起点开始播放。来源本身继续保留；本次新增的复制规则不会复制到自己的模板里，避免自动递归。

这是应用预设时建立的一份模板，后续修改来源不会自动重做它。需要调整所有副本的动画时，在来源下方选中关联模板卡片修改；所有引用该模板的副本一起使用新设置。原来就有的生成行为仍保留，复杂的多级生成受现有的四代限制。

默认 **每50帧复制一次**（50 FPS 下每秒一次），可在“行为 → 循环生成”修改间隔、首次延迟；间隔设为 **0** 只生成一轮。“复制obj”拖到发射器时，默认复制整个发射器；若要让每颗飞行子弹复制，可以切换“生成来源”。

### 排列方式

| 方式 | 设置与结果 |
| --- | --- |
| 上下左右复制 | 独立勾选四个方向，设置每方向层数与像素间距。间距100、层数2，会在距来源100和200像素处分别复制。 |
| 网格铺满复制 | 设置 X/Y 间距、网格宽度与高度（都是像素），再设置网格旋转角。格点围绕来源中心排列；例如宽400、高200、间距各100，得到5列3行。 |
| 圆周复制 | 设置副本数、半径和起始角，副本等距围成一圈。0度向右，90度向上。 |

“包含中心格点”控制是否在来源中心额外重叠一份；它只影响实际存在中心格点的排列。网格列数或行数为偶数时，格点对称分布在中心两侧。网格旋转围绕来源中心进行，宽高表示旋转前的范围。每轮最多300份。

### 朝向与颜色

**副本朝向**可选择保持来源朝向、指定朝向、朝向中心、背向中心或沿圆周切线，再用“副本朝向偏移”修正。比如星星的尖端原本朝上，可用偏移让它朝向圆心；动画中的后续旋转仍会相对于副本初始朝向继续。

**副本配色**有继承来源颜色、固定颜色、按副本顺序彩虹。彩虹的起始色相和颜色密度可调整，密度为负时反转顺序。

- 普通贴图使用混色，因此需要白色底图才能完整显示指定颜色。
- 来源启用彩虹 Cherry 时，彩虹副本会选取对应的彩虹贴图帧并固定，每份副本保持自己的颜色；继承模式保留原有成员的彩虹分布。
- 分组默认保留子物件各自的贴图；整体配色仍会作用于子物件。

示例：选中一个星星整体对象，拖入“复制obj”，选圆周复制、数量12、半径220、朝向中心、配色按副本顺序彩虹，间隔0。结果是在来源周围生成12份朝内的彩虹星星，来源继续存在。可以开启原星星的彩虹 Cherry，或用白色贴图配合彩虹混色。

## 片段紧贴与整理

时间轴的结束帧包含在物件时段内。因此 A 在49帧结束、B 在50帧开始时，它们正好相接。现在长条会紧贴绘制，连接处显示一条细白线；不会为这条线改变执行帧或增加空白帧。原有边缘吸附仍在“吸附”菜单中设置。

下栏顶部 **整理时间轴** 会按变量、事件/控制、拉镜、特效、脚本、分组、发射器、整体对象、普通对象的顺序分配轨道，再按形状或功能细分。同类且时间不重叠的物件可共用一轨，重叠物件分配相邻轨道；引用模板仍跟着来源显示。

整理只改变纵向位置，不改物件时间、参数、随机结果、绘制层次或原有执行先后。**Ctrl+Z** 可撤销一次整理。

## 拉伸时怎样处理关键帧

下栏顶部 **拉伸关键帧** 有四种模式，选择随工作区保存。鼠标拉边界、右栏起止输入和多选改边界使用同一设置。

| 模式 | 行为 |
| --- | --- |
| 保持关键帧时间 | 只改物件边界，关键帧保留原来的歌曲帧；超出可见范围的键不删除。 |
| 同步关键帧（密集预设重复） | 默认模式。普通关键帧按比例缩放；拉镜/特效中某属性至少有8颗键时，重复原样式填满新时段。已建立重复样式的物件继续使用该样式。 |
| 全部按比例缩放 | 将已有关键帧一起拉长或压短，包括密集特效。 |
| 重复样式填满 | 对当前物件明确使用循环填充，适合需要反复摇摆、闪烁的手工动画。 |

重复模式记录原来的一个周期，包含首尾帧：0～20帧的样式有21帧，下一轮从21帧开始。缩短后再拉长仍使用原周期，最后一个周期只填到结束帧；无需先手动复制整段。修改重复后的键再拉伸，会把编辑后的动画重新作为样式。这个操作可撤销，复制、保存、自定义预设和跨帧率导入会保留周期数据。

已绑定的**动作预设**继续由路径参数控制，改长短会重新逐帧铺设 X/Y；不把一段抛物线路径当作可平铺的振荡样式。其他属性按上述模式处理。
