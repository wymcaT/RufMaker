# 事件预设

在左栏打开 **预设 → 事件**。把事件拖到下栏时间轴，落点就是触发帧；双击则放在当前播放头。不需要先选来源物件，事件默认作用于全局。

新事件默认只有一帧。选中后可在右栏修改开始、结束帧，也能像其他物件一样移动、复制、撤销或存为自定义预设。把它拉长后，会在该时段内每帧执行，包含期间新生的弹幕。

| 事件 | 执行内容 |
| --- | --- |
| 清除全屏子弹 | 立即移除已有的飞行子弹，包括生成模板发出的子弹、释放后的队形成员和正在淡出/缩小的子弹。保留未释放的整体对象。 |
| 清除全屏所有弹幕 | 清除飞行子弹，并移除当前整体对象和可视对象；不会在下一帧重新绘制。发射器继续工作，之后才出场的物件保留。 |
| 所有子弹速度归零 | 触发帧速度为0。不会抹去加速、追踪和年龄行为，它们可以在后续帧继续生效。拉长事件时段可以持续停速。 |
| 重设所有子弹运动属性 | 可恢复每颗子弹出生时的速度和方向，或填写统一速度、方向、加速度、转向。可勾选停止后续年龄运动行为、追踪和运动表达式，外观、寿命和生成行为继续保留。后续时间轴控制事件仍可改变子弹。 |

这里的“全屏”表示所有现存目标，也包含房间或镜头外的子弹。不会删除玩家、房间地形、镜头或画面特效。出生延迟尚未结束的子弹会在真正出生时执行该时刻的事件；一次清弹不会取消未来所有发射。

例如，想在歌曲第500帧清屏，再在第550帧进入下一段，就把“清除全屏所有弹幕”放到500帧，新一段物件的开始帧设为550。想在500～550帧期间持续清弹，则把清弹事件的结束帧拉到550。

## 原生工程的子弹

默认处理 RufMaker 创建的弹幕。需要处理原生代码创建的子弹时，在右栏 **额外原生弹幕对象** 填入对象名，多个用逗号分隔，如 `obj_wymdan,objCherry`。会处理这些对象及其子类。编辑器不会自动把玩家、地形或控制器猜成子弹；请填写实际弹幕类。

额外原生对象在 F5 和导出的游戏中执行。运动重设使用事件里的自定义数值，修改 GM 内建的速度、方向、重力和摩擦；原对象的手写 Step 代码仍可能再次改写它们，出生运动也无法从任意原生代码中推算。

**原生底片是已经录制好的画面，事件不会修改录像中的弹幕。** RufMaker 后加内容正常实时响应事件；需要判断原生对象的实际效果时使用 F5。不要为了这类事件在每次拖动播放头时重启原游戏。

## 调整右栏

右栏关键帧区与参数区之间有一条横向分隔条，按住上下拖动即可分配高度，关闭时会保存。点击“关键帧”标题可暂时收起。文字较大时关键帧行和刻度会一起调整，不会只剩滚动条；上方起点、终点按钮与时间条也分别保留完整高度。
