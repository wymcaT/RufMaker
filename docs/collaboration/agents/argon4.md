# Argon4 任务记录

这是交接占位文件，不表示 Antigravity 已启动或 Argon4 已读过本仓库。实际接手后由 Argon4 自己维护；Codex 不代写执行结果。

- 状态：`not_started`
- 当前任务：未接单；有明确用户任务时优先用户任务，否则可选 STATUS 中未占用的 A1。
- 基线分支/SHA：接手时填写实际命令结果。
- 当前占用文件：无。
- 验收方式：接单时填写。

## 开始工作时填写

```text
状态：in_progress
任务编号/目标：
基线分支 / SHA：
占用文件（写具体文件，暂不确定时写新增目录范围）：
拟改接口 / 数据字段：无，或列出兼容约定
定向验证命令：
是否需要集成者共同重建 EXE：
```

## 完成或交接时填写

```text
状态：completed / awaiting_integration / blocked
实际改动文件：
接口与兼容性变化：
执行的命令及结果：
本地提交 SHA（如有）：
尚未验证的范围 / 具体阻塞：
供集成者执行的下一步：
当前占用文件：无，或明确仍需保留的范围
```

不要把构建成功写成用户试玩通过；不要把本机 `build/` 里的历史结果写成自己刚执行的结果。
