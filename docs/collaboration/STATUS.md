- 弹幕自身的年龄行为条块：速度、方向、大小、不透明度、加速度、转向、瞄准、追踪、碰撞、销毁、分裂。

- 直线、环、弧、椭圆、正弦及贝塞尔阵列；编号表达式、逐颗延迟、出生随机取样范围；曲线控制点可拖动。
- 父子分组、整体队形释放、子弹模板与分裂、复制时引用 ID 重映射。
- 可循环/嵌套片段、时间倍率、拆开编辑，以及通过原有自定义预设库保存复用。
- F5 玩家轨迹记录与预览使用，模拟检查点用于倒拖；源片段保存与导出展开分开处理。
- Beta.2：集成 Argon4 的撤销选中恢复，覆盖单项属性、连续撤销/重做、关键帧、多选与房间实例。补充撤销删除物件的回归检查；搜索和非属性输入框保留各自的文本编辑快捷键处理。
- Beta.2：整体对象加入心形（heart）、星星（star2）、星形轮廓、椭圆、花朵、∞ 形。前两者使用用户 Verse3 工程的原脚本公式；原文件原样收入 `assets/gml/formations/`，同步时只补缺少的同名脚本，不覆盖已有脚本。高度比例、内凹比例等可独立设关键帧。
- 1.12.0：物件自身的 `spawnActions` 与弹幕年龄行为 `type=spawn` 可生成普通物件、整体对象、发射器或分组模板；支持局部时间、重复触发、编号/奇偶筛选、偏移、方向继承与生成后销毁。
