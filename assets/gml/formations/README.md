# 整体形状的原始脚本

`heart.gml`、`star2.gml` 按字节复制自用户提供的 `non-ruf projects/Verse3/scripts/`。保留原函数参数、变量、实例编号和脚本内容。源文件的旧注释已有乱码，未改动算法或重新保存编码。

- `heart(number, speed, object, x, y, dir)`：原心形发射脚本。
- `star2(n, number, speed, object, x, y, dir)`：连接正 n 边形的第 k 与第 k+2 个顶点；`number` 是每段的弹数，n=5 时是交叉五角星。

工程同步时会补入缺少的同名脚本，并登记到 GameMaker 脚本资源中。工程已有 `heart` / `star2` 时保留已有内容，用户仍可直接在 GML 中调用。

界面的“心形（heart）”和“星星（star2）”从这些脚本的速度/方向公式还原出排列坐标，额外支持半径、朝向、关键帧与滚动。心形的半径是原公式坐标的 16 倍单位基准，界面朝向 0 为竖直心形（等价原 `heart` 的 dir=-90）；按原脚本从第 1 颗开始取样。星星按原脚本 k→k+2 的顺序取样；界面“弹幕数量”是总数，取尖角数的整数倍时对应原脚本每段相同的 `number`。

“星形轮廓”、椭圆、花朵、∞ 形是新增的独立种类，不替换原星星/心形公式。角度控制沿线相位；轮廓朝向控制整形旋转。非圆曲线按参数取样，滚动速度用轮廓长度估算。
